# 우리자산관리.xlsx 기능 매핑

> 상태: 초안(Draft)
> 문서 목적: 기존 자산관리 Excel의 기능이 차곡으로 이전되는 위치를 추적한다.

## 1. 기본 원칙

`우리자산관리.xlsx`는 차곡 초기 요구사항의 원본 자료로 사용한다.

단, Excel Sheet 하나를 화면 하나 또는 DB Table 하나로 그대로 변환하지 않는다.

```text
Excel Sheet
→ 현재 사용 목적 분석
→ 차곡 기능 정의
→ 화면/도메인으로 재배치
```

## 3. Excel에서 애플리케이션으로 이전 시 제거할 구조

### 3.1 계산용 중간 시트

Excel에서 화면 계산을 위해 존재하는 중간 셀/보조표는 애플리케이션 화면으로 그대로 이전하지 않는다.

- DB Query
- Domain Service
- 집계 Query
- 화면 ViewModel

등 적절한 계층으로 이동한다.

### 3.2 중복 입력

여러 Sheet에서 동일한 카드, 구성원, 카테고리 등을 반복 관리하는 구조는 기준정보로 통합한다.

예:

```text
카드설정 ─┐
카드거래 ─┼→ Card 기준정보
카드실적 ─┘
```

### 3.3 사용자 수식 의존

사용자가 Excel 수식을 직접 수정해야 하는 기능은 애플리케이션의 업무 로직으로 이동한다.

### 3.4 legacy 시트 의존

임시 Excel에서는 과거 연말 평가액 재현을 위해 `90_legacy_*투자금액현황` 등 legacy 시트를 참조할 수 있다.

차곡 본 개발에서는 legacy 시트를 런타임 데이터 소스로 사용하지 않으며 다음 데이터로 대체한다.

- 투자내역/투자금 현금흐름
- 투자계좌 및 보유종목
- 기준시점 평가 스냅샷
- 투자 성과 집계 로직

## 4. 유지해야 하는 핵심 업무 개념

Excel 구현 방식은 변경할 수 있지만 다음 사용자 관점의 기능은 유지 대상으로 본다.

- 가계 전체 재무상태 확인
- 구성원별 자산 구분
- 금융자산 관리
- 투자자산 평가 및 포트폴리오 관리
- 총 투자원금/평가손익/총 수익률 확인
- 연도별 투자금 및 연간 수익률 확인
- 실제 투자일을 반영한 XIRR 확인
- 연도·계좌별 투자금액 확인
- 카드 거래 분류
- 지출 반영/제외
- 거래 중복 확인
- 카드 실적 확인
- 월 수입 분석
- 정기 현금흐름 관리
- 부채 관리
- 월별 순자산 추적
- 카테고리 및 선택값 관리

## 5. 투자 성과 상세 매핑

투자 성과 계산은 `06-investment-performance.md`를 기준 명세로 사용한다.

| Excel 데이터/표시 | 임시 Excel 계산 기준 | 차곡 적용 위치 |
|---|---|---|
| 총 투자원금 | 08~09 투자입금 이력 합계 | FTR-204, FTR-206 |
| 현재 총 평가금액 | `03_주식투자관리` 계좌 총액 합계 | FTR-203~204 |
| 총 수익률 | `(현재 평가금액 - 총 투자원금) / 총 투자원금` | FTR-204 |
| 해당연도 투자액 | 08~09 투자입금 이력을 연도별 합산 | FTR-207 |
| 연초 평가액 | 임시로 legacy 확정 평가액 참조 | FTR-207, 평가 스냅샷 |
| 연말 평가액 | 과거 연도는 legacy 확정 평가액, 현재 연도는 최신 평가액 | FTR-207~208 |
| 연간 수익률 | `(연말/현재 평가액 - (연초 평가액 + 해당연도 투자액)) / (연초 평가액 + 해당연도 투자액)` | FTR-207 |
| 연 복리 수익률(XIRR) | 투자입금 실제 일자별 음수 현금흐름 + 현재 평가액 양수 현금흐름 | FTR-208 |
| 연도·계좌별 투자금액 | 투자입금 이력을 연도+계좌 기준으로 그룹 집계 | FTR-207~208 |

### 5.1 임시 Excel과 차곡의 차이

임시 Excel은 과거 연말 평가금액을 복원하기 위해 hidden legacy 시트를 참조한다.

차곡에서는 다음 흐름으로 대체한다.

```text
투자 거래/외부 자금 흐름
+ 투자계좌 현재 상태
+ 평가 스냅샷
→ 투자 성과 집계 서비스
→ SCR-020 투자 포트폴리오
```

### 5.2 수익률 지표 구분

- `총 수익률`: 현재 누적 평가손익을 투자원금과 비교한 값
- `연간 수익률`: 기존 Excel 호환 방식의 연도별 단순 성과율
- `XIRR`: 실제 투자일자를 반영한 연환산 내부수익률

세 지표는 의미가 다르므로 서로 대체하지 않는다.

## 6. 별도 상세 분석이 필요한 영역

다음 영역은 실제 Excel 계산식과 사용 방식에 대한 추가 확인 후 요구사항을 확정한다.

- `01_대시보드`의 각 KPI 계산식
- `04_거래원장`과 `11_카드거래관리`의 데이터 중복 여부
- 카드 실적 인정/제외 조건
- 월 수입 분석에서 저축/투자/지출의 분류 기준
- 정기 현금흐름이 거래원장에 반영되는 방식
- 부채 상환액의 지출 집계 방식
- 순자산 스냅샷 생성 방식
- 투자금 이체와 실제 매수 거래의 관계
- 배당/이자 수익의 투자 성과 반영 방식

`03_주식투자관리`의 투자원금/총 수익률/연도별 수익률/XIRR 계산 기준과 08~09 투자입금 이력의 투자 성과 역할은 1차 상세 분석을 완료했으며 `06-investment-performance.md`에서 관리한다.

| 최신 기준일 ETF 조회 | FTR-200 | 완료 |
| ETF 종목명 검색 | FTR-200 | 완료 |

| 다중 ETF 가격 관리 | SCR-020 기반기능 | PoC 완료 |

| 실제 투자일자 기반 XIRR 계산 복원 | FTR-208 | 임시 Excel 검증 완료 |

PoC 구현은 외부 연동 검증 목적이며 본 개발 시 도메인/API 구조는 재설계할 수 있다.
