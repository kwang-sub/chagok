# SCR-022 투자 내역

> 상태: 화면 구성 확정
> 상위 문서: `docs/product/03-screen-specification.md`
> 연계 화면: `SCR-020 투자 포트폴리오`, `SCR-050 계좌·카드 정보 관리`
> 디자인 기준: 확정된 투자금 투입 이력 PC/Mobile 시안

## 1. 화면 목적

정기 투자, 추가 납입, 일시 투자 등 `투자금 투입`의 전체 이력을 조회하고 각 투자 건의 진행상태, 매수/매도 제안, 실행 결과를 확인한다.

이 화면은 종목별 체결 내역을 상세 회계장부처럼 관리하는 화면이 아니라, 투자금이 언제 어떤 계좌에 투입되었고 그 투자 건이 어떻게 처리되었는지를 추적하는 실행 이력 화면이다.

## 2. 핵심 관리 원칙

- 투자금 투입 유형은 `정기 투자`, `추가 납입`, `일시 투자` 등으로 확장 가능하게 관리한다.
- 한 투자금 투입 건은 하나의 실행 단위로 관리한다.
- 투자 건에는 계좌, 명의, 금액, 예정일/실행일, 상태, 메모를 기록한다.
- 투자 제안과 실제 실행 결과를 구분하여 조회할 수 있어야 한다.
- 종목별 정확한 체결단가·체결시간을 모두 입력하는 것은 필수 요구사항이 아니다.
- 실제 거래 후 `매수 완료`, `매도 완료`, `건너뜀` 등 결과만 기록할 수 있다.
- 보유수량/평균매입가의 최종값은 `SCR-020 투자 포트폴리오`에서 보정할 수 있다.

## 3. 화면 구성

### 3.1 PC

PC는 다음 구조를 사용한다.

1. 상단 유형 탭
   - 전체 내역
   - 정기 투자
   - 추가 납입
   - 일시 투자
2. 요약 KPI
   - 총 투자금
   - 완료 금액
   - 진행중 금액
   - 보류 금액
   - 건너뛰기 금액
3. 필터/검색
   - 기간
   - 투자유형
   - 계좌
   - 상태
   - 메모/키워드
4. 투자 내역 테이블
5. 투자 내역 상세 Drawer

### 3.2 Mobile

Mobile은 목록 중심으로 구성한다.

- 상단 유형 탭
- 요약 KPI
- 필터 버튼
- 투자 내역 카드 목록
- 투자 건 선택 시 별도 상세 화면

## 4. 투자 내역 목록

PC 테이블 후보 컬럼:

- 투자일/예정일
- 투자유형
- 계좌
- 명의
- 투자금액
- 상태
- 완료일
- 매수/매도 결과 요약
- 메모
- 상세

Mobile 카드 필수 정보:

- 투자일 또는 예정일
- 투자유형
- 계좌
- 금액
- 상태

선택 노출 정보:

- 완료일
- 메모 요약
- 실행 결과 요약

## 5. 상태 정의

투자금 투입/실행 상태는 다음을 기본으로 한다.

```text
예정
사용가능
보류
진행중
완료
건너뜀
비활성화
```

UI에서는 사용자 이해를 위해 다음처럼 노출할 수 있다.

- `예정`: 아직 투자 예정일 전
- `사용가능`: 투자 가능한 상태
- `보류`: 사용자가 잠시 미룬 상태
- `진행중`: 투자 제안 확인 또는 일부 종목 처리 중
- `완료`: 투자 실행이 끝난 상태
- `건너뜀`: 해당 회차를 실행하지 않음
- `비활성화`: 잘못 생성했거나 관리 대상에서 제외

## 6. 투자 내역 상세

상세 화면에서는 다음을 제공한다.

### 기본 정보

- 투자금 투입 유형
- 예정일
- 실제 처리일
- 투자계좌
- 명의
- 투자금액
- 상태
- 메모

### 투자 제안

- 종목명
- 목표비중
- 현재비중
- 제안금액
- 예상수량
- 투자 후 예상비중

### 실행 결과

- 종목명
- 처리상태
- 실제 반영금액(선택)
- 실제 반영수량(선택)
- 메모

실제 체결단가 입력은 필수로 요구하지 않는다.

## 7. 재사용 기능

완료 또는 과거 투자 건을 기준으로 다시 투자할 수 있다.

예:

```text
[다시 투자하기]
```

동작:

- 기존 투자금/계좌/조건을 기본값으로 복사
- 새로운 투자금 투입 건 생성
- 기존 이력은 변경하지 않음

향후 `복사하여 새로 등록` 기능도 제공할 수 있다.

## 8. 투자하기 진입

정기 투자 알림에서 `진행`을 선택하거나, 투자 내역에서 대기 건을 선택한 경우 `투자하기` 화면으로 이동한다.

```text
투자 건 확인
→ 투자금/계좌 확인
→ 투자 시뮬레이션
→ 매수/매도 제안 확인
→ 진행
→ 완료 처리
```

## 9. 투자 제안과 실행 결과 구분

투자 제안은 계산 결과이며 실제 거래 결과와 다를 수 있다.

따라서 상세 화면에서는 반드시 `매수/매도 제안`과 `실행 결과`를 별도 탭 또는 영역으로 구분한다.

예:

```text
[매수/매도 제안] [실행 결과] [메모/이력]
```

## 10. 기간/유형/계좌 필터

지원 필터:

- 기간
- 투자금 투입 유형
- 투자계좌
- 명의
- 상태

기본 정렬은 최신 예정일/투자일 순으로 한다.

## 11. 통계 요약

상단 요약은 현재 필터 조건을 기준으로 계산한다.

- 총 투자금
- 완료 금액
- 진행중 금액
- 보류 금액
- 건너뛰기 금액
- 건수

향후 기간별/계좌별 투자금 추이 차트로 확장할 수 있다.

## 12. 권한

- 같은 가계 구성원의 투자 내역은 조회할 수 있다.
- 다른 구성원의 상세 실행 결과도 조회 가능하다.
- 투자 건의 등록, 수정, 진행, 보류, 건너뛰기, 완료 처리는 해당 계좌 명의자만 가능하다.
- 다른 구성원의 투자 내역은 조회 전용이다.

## 13. 비활성화 정책

- 투자 내역은 물리 삭제하지 않는다.
- 잘못 생성된 투자금 투입 건은 비활성화할 수 있다.
- 비활성화 건은 기본 목록에서 제외할 수 있으나 이력은 보존한다.
- 완료/건너뜀 상태는 정상 이력이므로 비활성화와 구분한다.

## 14. 금액 및 정밀도

- 금액은 임의 반올림하지 않는다.
- 서버 계산은 `BigDecimal`을 사용한다.
- DB는 `DECIMAL/NUMERIC` 계열을 사용한다.
- 화면에서는 천 단위 구분자를 사용한다.

## 15. 시안 데이터 및 가명 원칙

화면 시안의 계좌명, 종목명, 구성원명, 금융기관명은 모두 가명/샘플 데이터를 사용한다.

실제 구현에서는 DB/API 조회값으로 치환한다.

## 16. Figma 전이 기준

```text
SCR-022 투자 내역 / Desktop
SCR-022 투자 내역 상세 / Desktop Drawer
SCR-022 투자 내역 / Mobile
SCR-022 투자 내역 상세 / Mobile
SCR-022 투자하기 / Mobile
SCR-022 매수매도 제안 / Mobile
```

확정된 시안의 밝은 배경, 녹색 포인트, 카드/테이블 정보 계층을 유지한다.

## 17. 연계 화면

- `SCR-020 투자 포트폴리오`: 보유자산/성과/투자금 실행 진입
- `SCR-050 계좌·카드 정보 관리`: 투자계좌 정보
- `SCR-001 홈 대시보드`: 투자 예정일 알림 및 투자 요약
- `SCR-040 현금흐름 현황`: 투자금 현금흐름 반영

## 18. 확정 사항

- 현재 시안을 `SCR-022` 기준 디자인으로 사용
- 투자 내역은 종목별 체결장부가 아니라 `투자금 투입 이력` 중심으로 관리
- 정기 투자/추가 납입/일시 투자 통합 조회
- 진행/보류/건너뜀/완료 상태 이력 제공
- 투자 제안과 실제 실행 결과를 분리
- 실제 체결단가/시간의 상세 입력은 필수 아님
- 과거 투자 건 기준 `다시 투자하기` 가능
- 같은 가계 구성원은 조회 가능, 변경은 계좌 명의자만 가능
- 물리 삭제하지 않고 비활성화 정책 사용

## 19. 추후 확정

- `다시 투자하기` 시 복사되는 기본값 범위
- 실제 반영금액/수량 입력을 필수 또는 선택으로 할지
- 투자 내역 통계/차트 상세 범위
- 보류 건 재알림 정책
- 투자 완료 후 평균매입가 보정 유도 UX
