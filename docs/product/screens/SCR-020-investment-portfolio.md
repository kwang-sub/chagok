# SCR-020 투자 포트폴리오

> 상태: 화면 구성 확정
> 상위 문서: `docs/product/03-screen-specification.md`
> 연계 화면: `SCR-050 계좌·카드 정보 관리`, `SCR-022 투자 내역`
> 디자인 기준: 투자금 투입 기반으로 확정한 PC/Mobile 최종 시안

## 1. 화면 목적

보유 투자자산의 평가현황과 자산배분을 확인하고, 투자계좌에 투입되는 자금을 현재/목표 비중에 따라 효율적으로 투자할 수 있도록 실행을 지원한다.

차곡은 증권사의 주문 기능을 대체하지 않는다. 사용자가 정기 또는 추가로 투자금을 마련하면 차곡이 투자 시뮬레이션을 제공하고, 사용자가 실제 거래 후 완료 상태와 최종 보유정보를 반영하는 방식으로 동작한다.

## 2. 핵심 투자 관리 원칙

- 상위 개념은 `투자금 투입(Investment Funding)`으로 정의한다.
- 정기 투자는 투자금 투입의 한 유형이며 전체 모델을 월 예약 투자에 종속시키지 않는다.
- 추가 납입, 일시 투자, 보너스 투자 등 향후 투자금 유형을 동일 구조로 확장할 수 있어야 한다.
- 종목별 모든 매수 lot과 실제 체결정보를 세세하게 기록하는 것은 필수 요구사항이 아니다.
- 포트폴리오는 보유수량, 평균매입가, 현재가, 평가금액, 현재비중, 목표비중을 중심으로 관리한다.
- 투자금이 사용 가능해지면 현재/목표 비중을 기준으로 종목별 매수 필요금액과 예상수량을 계산한다.
- 실제 주문은 사용자가 증권사에서 직접 수행한다.
- 실제 거래 후 완료 상태를 기록하고 최종 보유수량/평균매입가는 필요 시 사용자가 보정한다.
- 금액·수량·수익률 계산은 `BigDecimal` 기반 정밀도 정책을 따른다.

## 3. 투자금 투입 유형

```text
투자금 투입
├─ 정기 투자
│  └─ 반복 일정과 금액을 사전 등록
├─ 추가 납입
│  └─ 필요할 때 사용자가 임의 금액 추가
└─ 일시 투자
   └─ 보너스 등 비정기 투자금 확장
```

초기 구현은 정기 투자를 우선 지원하되 `추가 납입`을 독립적인 투자금 투입 건으로 추가할 수 있는 화면/도메인 구조를 유지한다.

## 4. PC 화면 구성 확정

PC는 다음 영역으로 구성한다.

1. 상단 탭
   - 포트폴리오
   - 투자금 투입
   - 계좌별
   - 종목별
   - 성과 분석
2. 포트폴리오 KPI
   - 총 평가금액
   - 총 투자원금
   - 평가손익
   - 연환산 수익률
3. 투자 실행 안내
   - 도래한 정기 투자
   - 추가 납입 진입점
4. 자산 배분
5. 평가금액/수익률 추이
6. 보유 종목 테이블
7. 최근 투자금 투입 내역
8. 다음 예정 투자금

PC 상단의 주요 액션은 `+ 투자금 추가`로 제공한다.

## 5. Mobile 화면 구성 확정

Mobile은 사용빈도가 높은 동작을 중심으로 다음 화면 흐름을 사용한다.

### 홈/투자 알림

투자 예정일이 도래하면 즉시 확인할 수 있는 카드 형태로 제공한다.

```text
오늘은 투자일입니다.
A계좌에 1,000,000원을 투자할 예정입니다.
지금 투자하시겠습니까?

[투자하기] [보류] [건너뛰기]
```

### 투자하기

```text
[정기 투자] [추가 납입] [일시 투자]

A계좌
사용 가능한 투자금 1,000,000원

투자 시뮬레이션
종목 | 목표비중 | 제안금액 | 예상수량
...

[보류] [건너뛰기] [진행하기]
```

### 보유 종목

종목별 현재 평가금액과 수익률을 빠르게 조회한다.

### 종목 상세

보유수량, 평균매입가, 현재가, 평가금액, 평가손익, 현재비중, 목표비중을 제공한다. 본인 종목은 평균매입가와 보유정보를 보정할 수 있다.

## 6. 핵심 지표

- 총 평가금액
- 누적 투자원금
- 평가손익
- 단순 수익률
- 연환산 수익률
- 자산배분
- 다음 투자 예정일/금액
- 사용 가능한 추가 투자금
- 가격 데이터 조회일시

### 단순 수익률

```text
단순 수익률 = 평가손익 / 누적 투자원금 × 100
```

### 연환산 수익률

종목별 매수 lot 대신 계좌/포트폴리오의 실제 투자금 투입 현금흐름을 기준으로 계산한다.

최종 계산 방식은 기존 `우리자산관리`의 연복리 계산 결과와 회귀 검증 후 확정한다.

후보:

- XIRR / 금액가중수익률(MWRR)
- 기존 시트의 연복리 계산 방식

## 7. 정기 투자 계획

정기 투자 계획 후보 필드:

- 투자계좌
- 명의
- 예정 투자금
- 반복 투자일
- 시작월
- 종료월(선택)
- 메모

종료월이 없으면 계속 유효한 계획으로 본다.

투자 계획과 실제 투자금 투입/실행 이력은 분리한다.

## 8. 투자 예정일 알림

정기 투자 예정일이 도래하면 홈 또는 투자 화면에서 투자 실행 안내를 제공한다.

사용자 선택:

### 진행

- 예약 계좌와 금액을 기본값으로 사용한다.
- 투자 시뮬레이션으로 이동한다.

### 보류

- 해당 투자 건을 대기 상태로 유지한다.
- 이후 다시 실행할 수 있다.

### 건너뛰기

- 해당 회차만 건너뛴다.
- 반복 투자 계획 자체는 유지한다.
- 건너뛴 회차를 이력으로 보존한다.

## 9. 추가 납입

추가 납입은 정기 투자와 독립된 투자금 투입이다.

```text
+ 투자금 추가
→ 추가 납입
→ 계좌 선택
→ 금액 입력
→ 투자금 사용가능 상태
→ 투자 시뮬레이션
→ 실제 주문
→ 완료 처리
```

같은 달에 정기 투자와 추가 납입이 동시에 존재할 수 있다.

추가 납입은 정기 투자 계획의 예정금액을 변경하지 않는다.

## 10. 투자 시뮬레이션

사용 가능한 투자금을 현재/목표 비중에 따라 배분한다.

예시:

```text
A계좌 / 사용 가능한 투자금 1,000,000원

종목          현재비중   목표비중   제안금액   예상수량   투자후 예상비중
샘플 ETF A     32%       40%      450,000원    15주       37.8%
샘플 ETF B     38%       35%            0원     -         35.1%
샘플 ETF C     30%       25%      550,000원    11주       27.1%
```

초기 기본 모드는 `신규 투자금으로 부족 비중을 보정하는 매수 중심 방식`으로 한다.

화면에는 다음을 제공한다.

- 종목명
- 현재 비중
- 목표 비중
- 비중 차이
- 제안 금액
- 계산에 사용한 현재가
- 예상 매수수량
- 투자 후 예상 비중
- 가격 데이터 기준일시

예상수량은 시뮬레이션이며 실제 체결 결과와 다를 수 있음을 표시한다.

## 11. 투자 실행 상태

투자금 투입 건 상태 후보:

```text
예정
사용가능
보류
진행중
완료
건너뜀
비활성화
```

종목별 제안 처리 상태:

```text
대기
매수 완료
매도 완료
건너뜀
```

실제 증권사 거래 후 완료 버튼을 처리하는 것이 기본 흐름이다.

## 12. 보유 종목 관리

보유 종목 테이블/목록의 핵심 정보:

- 종목명/티커
- 투자계좌
- 보유수량
- 평균매입가
- 현재가
- 평가금액
- 평가손익
- 단순 수익률
- 목표비중
- 현재비중

종목별 매수 lot 목록은 제공하지 않는다.

## 13. 종목 상세 및 평균매입가 보정

종목 상세:

- 종목명/티커
- 투자계좌
- 보유수량
- 평균매입가
- 현재가
- 평가금액
- 평가손익
- 단순 수익률
- 목표비중
- 현재비중
- 가격 데이터 조회일시

본인 소유 종목은 다음을 보정할 수 있다.

- 보유수량
- 평균매입가
- 목표비중

평균매입가 변경 시 변경일시를 기록하고 가능하면 이전 값을 이력으로 보존한다.

## 14. 성과 분석

- 계좌별 수익률
- 전체 포트폴리오 수익률
- 기간별 평가금액 추이
- 기간별 투자원금 추이
- 단순 수익률 추이
- 연환산 수익률 추이
- 자산배분 변화

연도별 투자성과는 기존 Excel 기능을 앱에서도 유지한다.

## 15. 가격 데이터 정책

- 시세 조회 실패 시 마지막 정상 가격을 사용한다.
- 가격 데이터 조회일시를 표시한다.
- 투자 시뮬레이션에는 예상수량 계산에 사용한 가격 기준일시를 반드시 제공한다.

## 16. 권한

- 같은 가계 구성원의 포트폴리오와 투자 실행 현황은 조회할 수 있다.
- 투자 계획/투자금 투입 생성 및 변경은 해당 계좌 명의자만 가능하다.
- 진행/보류/건너뛰기 및 완료 처리는 해당 계좌 명의자만 가능하다.
- 보유수량/평균매입가/목표비중 변경 역시 해당 계좌 명의자만 가능하다.

## 17. 시안 데이터

화면 시안과 문서의 사람 이름, 계좌명, 금융기관, 종목은 가명/샘플 데이터를 사용한다. 실제 구현에서는 DB/API 조회값으로 치환한다.

## 18. 연계 화면

- `SCR-050`: 투자계좌 정보
- `SCR-022`: 투자금 투입 및 실행 이력
- `SCR-001`: 홈 투자 요약 및 투자일 알림
- `SCR-012`: 순자산 추이
- `SCR-060`: 투자성과가 포함되는 보고서

## 20. 확정 사항

- 현재 시안을 `SCR-020` 기준 디자인으로 사용
- 투자금 투입을 정기 투자에 종속시키지 않음
- 정기 투자 + 추가 납입 + 향후 일시 투자 확장 구조
- 투자일 알림에서 `진행 / 보류 / 건너뛰기`
- 투자금 기반 매수 시뮬레이션 제공
- 목표비중 대비 부족한 종목 중심으로 매수금액/예상수량 제공
- 실제 주문은 증권사에서 수행
- 차곡에서는 완료 처리 및 최종 보유정보 보정
- 평균매입가 직접 보정 가능
- 종목별 상세 매수 lot 추적은 필수 기능에서 제외
- 연환산 수익률은 투자금 투입 현금흐름을 기준으로 계산
- 연도별 투자성과 유지

## 21. 추후 확정

- 투자금 배분 알고리즘의 정확한 계산식
- 목표비중 합계 검증 정책
- ETF 1주 미만 잔여금액 처리
- 보류 건 재알림 정책
- 투자일이 휴일인 경우 처리
- 매도 포함 리밸런싱 모드
- 배당/수수료/세금 처리
- 해외자산/환율 처리
- 평균매입가 변경이력 상세 수준
- 실제 Push/Web 알림 전달 방식
