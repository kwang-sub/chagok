# SCR-020 투자 포트폴리오

> 상태: 화면 구성 검토 중
> 상위 문서: `docs/product/03-screen-specification.md`
> 연계 화면: `SCR-050 계좌·카드 정보 관리`, `SCR-022 투자 내역`

## 1. 화면 목적

보유 중인 투자자산의 평가금액, 투자원금, 평가손익, 현재 수익률, 자산배분과 함께 계좌별 투자금 투입과 투자 실행 계획을 관리한다.

차곡의 투자 포트폴리오는 종목별 모든 매수 lot을 세세하게 추적하는 방식이 아니라, 투자계좌에 투입되는 자금과 현재 보유 종목/평균매입가를 관리하고, 투자금이 발생했을 때 현재·목표 비중을 기준으로 투자 실행을 지원하는 것을 기본으로 한다.

## 2. 핵심 투자 관리 원칙

- 상위 개념은 `투자금 투입(Investment Funding)`으로 정의한다.
- 정기 월 투자금은 투자금 투입의 한 유형일 뿐 도메인 전체를 월 예약 투자에 종속시키지 않는다.
- 향후 추가 납입, 일시 납입, 보너스 투자, 임시 증액 등도 동일한 투자금 투입 흐름으로 처리할 수 있어야 한다.
- 실제 종목별 매수일·매수수량·매수단가를 거래 건마다 모두 입력하지 않는다.
- 포트폴리오는 현재 보유수량, 평균매입가, 현재가, 평가금액, 목표/현재 비중을 중심으로 관리한다.
- 투자금이 사용 가능해지면 현재 보유비중과 목표비중을 기준으로 종목별 매수 제안을 계산한다.
- 실제 주문은 증권사에서 사용자가 직접 수행하고 차곡에서는 완료 상태와 최종 보유정보를 관리한다.
- 실제 체결 결과와 차이가 생긴 경우 최종 보유수량 및 평균매입가를 사용자가 보정할 수 있다.
- 금액·수량·수익률 계산은 `BigDecimal` 기반 정밀도 정책을 따른다.

## 3. 투자금 투입 유형

초기 및 확장 가능한 투자금 유형은 다음과 같이 본다.

```text
투자금 투입
├─ 정기 투자
│  └─ 매월 지정일/지정금액
├─ 추가 납입
│  └─ 사용자가 필요할 때 임의 금액 투입
└─ 기타 일시 투자
   └─ 향후 보너스 투자, 임시 증액 등 확장
```

초기 구현에서는 `정기 투자`를 우선 지원하되 데이터 모델과 화면 흐름은 `추가 납입`을 자연스럽게 추가할 수 있도록 설계한다.

투자금 투입 공통 후보 필드:

- 투자계좌
- 명의
- 투입 유형
- 예정/실제 금액
- 예정일 또는 투입일
- 기준월(필요 시)
- 반복 여부
- 시작월/종료월(정기 투자일 때)
- 상태
- 메모

## 4. 핵심 지표

상단 요약에서는 다음 정보를 제공한다.

- 총 평가금액
- 누적 투자원금
- 총 평가손익
- 단순 수익률
- 계좌/포트폴리오 연환산 수익률
- 이번 달 예정 투자금
- 추가 투자 가능금액 또는 대기 중인 투자금(향후)
- 다음 투자 예정일
- 가격 데이터 조회일시

### 4.1 단순 수익률

```text
단순 수익률 = 평가손익 / 누적 투자원금 × 100
```

### 4.2 연환산 수익률

종목별 매수 lot을 추적하지 않으므로 종목별 정확한 투자기간 기반 연환산 수익률은 제공하지 않는다.

대신 계좌 또는 포트폴리오 단위의 투자금 투입 일자·금액과 현재 평가금액을 기반으로 연환산 수익률을 계산한다.

후보 계산 방식:

- 현금흐름 기반 XIRR/금액가중수익률(MWRR)
- 기존 `우리자산관리` 시트에서 사용하는 연복리 계산 방식

정확한 계산 방식은 기존 시트와 결과를 비교하는 회귀 검증 후 확정한다.

```text

[이번 달 예정 투자금] [다음 투자 예정일]      [+ 투자금 추가]

[자산 배분]                          [평가금액/수익률 추이]

[계좌 ▼] [자산유형 ▼] [국가/시장 ▼] [검색]

종목명 | 계좌 | 보유수량 | 평균매입가 | 현재가 | 평가금액 | 평가손익 | 수익률 | 현재비중 | 목표비중
------------------------------------------------------------------------------------------------
샘플 ETF A | 샘플증권 ISA | ...

```

`+ 투자금 추가`는 향후 추가 납입 기능을 위한 독립 진입점으로 사용할 수 있다.

```text

[투자하기]   [+ 추가 투자금]

```

초기에는 `+ 추가 투자금`이 비활성 또는 후속 기능 표시일 수 있으나 화면 구조상 정기 투자와 분리된 확장 지점을 유지한다.

## 7. 정기 투자 계획

사용자는 투자계좌별로 반복 투자 계획을 등록할 수 있다.

필수 후보 필드:

- 투자계좌
- 명의
- 예정 투자금
- 투자 예정일 또는 매월 투자일
- 시작월
- 종료월(선택)
- 반복 여부
- 메모

종료월이 없으면 반복 계획은 계속 유효한 것으로 본다.

정기 투자 계획은 실제 투자금 투입/실행 기록과 구분하여 관리한다.

## 8. 추가 납입 확장 원칙

향후 추가 납입 기능은 새로운 별도 투자 도메인을 만들지 않고 기존 `투자금 투입` 흐름을 재사용한다.

예시:

```text
+ 추가 투자금
→ 계좌 선택
→ 금액 입력
→ 투자금 투입 생성
→ 투자 실행 제안
→ 실제 주문
→ 완료 처리
```

추가 납입은 정기 투자 계획의 예정금액을 수정하지 않는다.

같은 달에 정기 투자와 추가 납입이 동시에 존재할 수 있으며 각각 별도 투자금 투입 이력으로 보존한다.

## 9. 투자 예정일 알림

정기 투자 예정일이 도래하면 앱 알림 또는 홈/투자 화면에 투자 실행 안내를 제공한다.

예시:

```text
투자 예정일이 도래했습니다.
A 계좌에 예정된 1,000,000원으로 투자를 진행하시겠습니까?

[진행] [보류] [건너뛰기]
```

### 진행

- 해당 투자금 투입 건의 계좌와 금액을 기본값으로 사용한다.
- 투자 실행 제안 화면으로 이동한다.

### 보류

- 투자금 투입 건을 대기 상태로 유지한다.
- 이후 다시 실행할 수 있다.

### 건너뛰기

- 해당 정기 투자 회차만 건너뛴다.
- 정기 투자 계획 자체는 유지한다.
- 다음 회차는 정상 생성한다.

추가 납입처럼 사용자가 즉시 생성한 투자금은 알림 단계를 거치지 않고 바로 투자 실행 제안으로 진입할 수 있다.

## 10. 투자 실행 제안

정기 투자든 추가 납입이든 `사용 가능한 투자금`이 존재하면 동일한 제안 로직을 사용한다.

예시:

```text
A 계좌 / 사용 가능한 투자금 1,000,000원

종목           현재비중   목표비중   제안금액    예상수량   상태
샘플 ETF A      32%       40%       450,000원    15주      매수
샘플 ETF B      38%       35%             0원     -        유지
샘플 ETF C      30%       25%       550,000원    11주      매수
```

초기 기본 모드는 신규 투자금을 부족 비중 종목에 배분하는 `매수 중심` 방식으로 한다.

제안 정보:

- 종목명
- 현재 평가금액
- 현재 비중
- 목표 비중
- 비중 차이
- 제안 거래 방향
- 제안 금액
- 현재가
- 현재가 기준 예상 수량
- 투자 후 예상 비중

## 11. 완료 처리

제안된 종목별 거래 상태:

```text
대기
매수 완료
매도 완료
건너뜀
```

실제 증권사에서 거래 후 완료 버튼만 처리하는 것을 기본으로 한다.

실제 체결로 보유수량이나 평균매입가가 달라진 경우 사용자가 최종 값을 보정한다.

모든 필요한 처리가 끝나면 해당 투자금 투입 건 또는 투자 실행 회차를 `완료` 처리한다.

## 12. 투자금 투입/실행 상태

투자금과 투자 실행을 유연하게 확장할 수 있도록 상태를 월 정기 투자에 한정하지 않는다.

후보 상태:

```text
예정
사용가능
보류
진행중
완료
건너뜀
비활성화
```

정기 투자의 `예정`과 추가 납입의 즉시 `사용가능`을 동일 모델에서 표현할 수 있어야 한다.

## 13. 종목 상세

종목 상세 표시 정보:

- 종목명 / 티커
- 투자계좌
- 보유수량
- 평균매입가
- 현재가
- 평가금액
- 평가손익
- 단순 수익률
- 현재 비중
- 목표 비중
- 가격 데이터 조회일시

본인 보유 종목은 다음 값을 수정할 수 있다.

- 보유수량
- 평균매입가
- 목표 비중

종목별 매수 lot 목록은 제공하지 않는다.

## 14. 평균매입가 보정

평균매입가는 모든 체결내역을 역산하여 자동 계산하는 것을 기본으로 하지 않는다.

사용자가 실제 증권사 계좌 값을 기준으로 필요 시 최종 평균매입가를 수정할 수 있다.

변경 시 변경일시와 가능하면 이전 값을 보존한다.

## 15. 투자 내역 연계

`SCR-022 투자 내역`에서는 최소 다음을 조회할 수 있어야 한다.

- 투자금 투입 유형(정기/추가/기타)
- 예정/실제 금액
- 계좌
- 예정일/투입일
- 진행/보류/건너뛰기 이력
- 투자 실행 상태
- 종목별 제안 금액/예상수량
- 매수 완료/매도 완료 상태

종목별 정확한 체결 단가·체결시간까지 기록하는 것은 필수 요구사항이 아니다.

## 16. 가격 데이터 정책

- 현재 시세 조회 실패 시 마지막 정상 가격을 사용할 수 있다.
- 마지막 정상 가격을 사용하는 경우 가격 데이터 조회일시를 제공한다.
- 투자 실행 제안 화면에서는 예상수량 계산에 사용한 가격 기준일시를 확인할 수 있어야 한다.

## 17. 권한

- 같은 가계 구성원의 포트폴리오는 조회할 수 있다.
- 투자 계획 및 투자금 투입의 등록/수정/비활성화는 해당 계좌 명의자만 수행한다.
- 진행/보류/건너뛰기 및 완료 처리 역시 해당 계좌 명의자만 가능하다.
- 다른 구성원의 투자 현황은 조회 전용이다.

## 18. 시안 데이터

화면 시안의 사람 이름, 계좌명, 금융기관, 종목 예시는 모두 가명/샘플 데이터를 사용한다. 실제 구현에서는 DB/API 조회값으로 치환한다.

## 19. 기존 Excel 연계

- `03_주식투자관리`
- 투자금 납입 관련 시트
- 기존 연도별 투자성과/연복리 수익률 계산 영역

기존 시트의 실제 계산식과 화면 결과를 기준으로 앱 계산 로직을 회귀 검증한다.

## 20. 확정 사항

- 투자금 관리는 `월 예약 투자금`이 아닌 상위 개념 `투자금 투입`으로 설계
- 정기 투자와 향후 추가 납입을 동일 모델에서 확장 가능하게 구성
- 정기 투자 예정일 도래 시 `진행 / 보류 / 건너뛰기` 제공
- 진행 시 해당 투자금과 계좌를 기본으로 투자 실행 제안 생성
- 추가 납입은 기존 정기 계획을 변경하지 않고 별도 투자금 투입 건으로 생성
- 현재/목표 비중을 기준으로 종목별 매수 필요 금액 및 예상수량 제공
- 초기 기본 모드는 신규 투자금 기반 매수 중심 리밸런싱
- 앱은 실제 주문을 실행하지 않음
- 실제 거래 후 완료 처리 및 최종 보유수량/평균매입가 보정
- 종목별 상세 매수 lot 추적은 필수 기능에서 제외
- 연환산 수익률은 계좌/포트폴리오의 실제 투자금 현금흐름을 기준으로 계산
