# SCR-020 투자 포트폴리오

> 상태: 화면 구성 검토 중
> 상위 문서: `docs/product/03-screen-specification.md`
> 연계 화면: `SCR-050 계좌·카드 정보 관리`, `SCR-022 투자 내역`

## 1. 화면 목적

보유 중인 투자자산의 평가금액, 투자원금, 평가손익, 현재 수익률, 자산배분과 함께 실제 매수시점을 반영한 장기 투자성과를 확인한다.

차곡의 투자 포트폴리오는 종목별 평균단가만 관리하지 않고, 분할매수된 각 매수 건의 일자·수량·단가를 보존하여 투자기간 기반 성과 계산이 가능해야 한다.

## 2. 필수 투자 데이터 원칙

- 하나의 종목은 여러 번 분할매수될 수 있다.
- 매수 건별 `매수일`, `매수수량`, `매수단가`, `매수금액`, `투자계좌`를 별도로 저장한다.
- 종목의 보유수량과 평균매입가는 매수 내역을 기반으로 계산 가능해야 한다.
- 단순 현재 수익률과 투자기간을 반영한 연환산 수익률을 구분하여 제공한다.
- 매수 이력을 합쳐 단일 최초매수일이나 단일 평균 매수일로 덮어쓰지 않는다.
- 금액·수량·수익률 계산은 정밀도 손실이 없도록 `BigDecimal` 기반 정책을 따른다.

## 3. 핵심 지표

상단 요약에서는 다음 정보를 제공한다.

- 총 평가금액
- 총 투자원금
- 총 평가손익
- 단순 수익률
- 연환산 수익률
- 가격 데이터 조회일시

### 3.1 단순 수익률

```text
단순 수익률 = 평가손익 / 투자원금 × 100
```

현재 평가손익을 확인하기 위한 지표이다.

### 3.2 연환산 수익률

분할매수가 존재하므로 단순 CAGR을 최초 매수일 하나에만 적용하지 않는다.

매수 시점이 서로 다른 복수 현금흐름을 반영할 수 있는 방식으로 계산해야 하며, 기존 `우리자산관리` 시트에서 사용 중인 연복리 수익률 계산식을 분석하여 최종 계산 규칙을 확정한다.

후보 계산 방식:

- 매수 lot별 보유기간 연환산 후 가중 집계
- 현금흐름 기반 XIRR/금액가중수익률(MWRR)

정확한 방식은 기존 시트와 결과가 일치하는지 회귀 검증 후 확정한다.

## 6. 종목 상세

종목 상세에서는 다음 정보를 제공한다.

- 종목명 / 티커
- 투자계좌
- 총 보유수량
- 총 투자원금
- 평균매입가
- 현재가
- 평가금액
- 평가손익
- 단순 수익률
- 연환산 수익률
- 최초 매수일
- 최근 매수일
- 가격 데이터 조회일시

### 6.1 분할매수 내역

종목 상세에서 매수 lot 목록을 확인할 수 있어야 한다.

```text
매수일      수량    매수단가     매수금액
2025-01-10  10      12,000원    120,000원
2025-02-14   5      11,500원     57,500원
2025-04-03  12      13,100원    157,200원
```

매수 내역 상세 편집은 `SCR-022 투자 내역`에서 수행하는 것을 기본으로 한다.

## 7. 가격 데이터 정책

- 현재 시세 조회 실패 시 마지막 정상 가격을 사용할 수 있다.
- 마지막 정상 가격을 사용하는 경우 반드시 가격 데이터 조회일시를 제공한다.
- 사용자가 최신 가격인지 과거 가격인지 식별할 수 있어야 한다.

## 8. 권한

- 같은 가계 구성원의 포트폴리오는 조회할 수 있다.
- 투자 내역의 등록/수정/비활성화는 해당 거래 당사자만 수행할 수 있다.
- 다른 구성원의 포트폴리오는 조회 전용이다.

## 9. 시안 데이터

화면 시안의 사람 이름, 계좌명, 금융기관, 종목 예시는 모두 가명/샘플 데이터를 사용한다. 실제 구현에서는 DB/API 조회값으로 치환한다.

## 10. 기존 Excel 연계

- `03_주식투자관리`
- 투자내역 관련 시트
- 기존 연도별 투자성과/연복리 수익률 계산 영역

기존 시트의 실제 계산식과 화면 결과를 기준으로 앱 계산 로직을 회귀 검증한다.

## 11. 확정 사항

- 분할매수 지원은 필수
- 매수일을 거래 건별로 보존
- 단순 수익률과 연환산 수익률을 별도 제공
- 연환산 수익률은 분할매수 시점을 반영
- 정확한 연복리 계산식은 기존 자산관리 시트와 결과 일치 검증 후 확정
- 종목 상세에서 분할매수 이력 조회
- 실제 수정은 투자내역 화면 중심으로 수행

## 12. 추후 확정

- 연환산 수익률의 최종 계산 방식(XIRR/MWRR 또는 기존 시트 방식)
- 매도 시 lot 차감 방식(FIFO/평균법/직접 지정)
- 배당금의 투자성과 포함 방식
- 수수료/세금의 투자원금 및 수익률 반영 방식
- 환율 변동을 포함한 해외자산 수익률 계산 방식
