# SCR-020 투자 포트폴리오

> 상태: 화면 구성 검토 중
> 상위 문서: `docs/product/03-screen-specification.md`
> 연계 화면: `SCR-050 계좌·카드 정보 관리`, `SCR-022 투자 내역`

## 1. 화면 목적

보유 중인 투자자산의 평가금액, 투자원금, 평가손익, 현재 수익률, 자산배분과 함께 월별 계좌 투자금 납입을 기준으로 한 투자성과를 확인한다.

차곡의 투자 포트폴리오는 종목별 모든 매수 lot을 세세하게 추적하는 방식이 아니라, 계좌별 월 투자금 납입과 현재 보유 종목/평균매입가를 관리하는 것을 기본으로 한다.

## 2. 핵심 투자 관리 원칙

- 사용자는 월별로 투자계좌에 투입한 투자금을 기록한다.
- 실제 종목별 매수일·매수수량·매수단가를 거래 건마다 모두 입력하지 않는다.
- 포트폴리오는 현재 보유수량, 평균매입가, 현재가, 평가금액, 목표/현재 비중을 중심으로 관리한다.
- 월 투자금 납입 시 현재 또는 목표 보유비중을 기준으로 종목별 매수/매도 제안을 계산한다.
- 사용자는 제안된 거래를 실제 증권사에서 수행한 뒤 `매수 완료` 또는 `매도 완료` 상태만 기록한다.
- 실제 체결 결과와 차이가 생긴 경우 종목의 최종 보유수량 및 평균매입가를 사용자가 수정하여 보정할 수 있다.
- 종목별 상세 매수 lot 이력은 필수 관리 대상이 아니다.
- 금액·수량·수익률 계산은 `BigDecimal` 기반 정밀도 정책을 따른다.

## 3. 핵심 지표

상단 요약에서는 다음 정보를 제공한다.

- 총 평가금액
- 누적 투자원금
- 총 평가손익
- 단순 수익률
- 계좌/포트폴리오 연환산 수익률
- 가격 데이터 조회일시

### 3.1 단순 수익률

```text
단순 수익률 = 평가손익 / 누적 투자원금 × 100
```

현재 평가상태를 빠르게 확인하는 지표이다.

### 3.2 연환산 수익률

종목별 매수 lot을 추적하지 않으므로 종목별 정확한 투자기간 기반 연환산 수익률은 제공하지 않는다.

대신 계좌 또는 포트폴리오 단위로 기록된 월별 투자금 납입 일자·금액과 현재 평가금액을 기반으로 연환산 수익률을 계산한다.

후보 계산 방식:

- 현금흐름 기반 XIRR/금액가중수익률(MWRR)
- 기존 `우리자산관리` 시트에서 사용하는 연복리 계산 방식

정확한 계산 방식은 기존 시트의 계산식과 앱 결과를 비교하는 회귀 검증 후 확정한다.

종목별로는 평균매입가 대비 현재가를 기준으로 한 단순 수익률을 제공한다.

## 6. 월 투자금 납입

투자계좌별로 월 투자금 납입을 기록한다.

필수 후보 필드:

- 기준월
- 납입일
- 투자계좌
- 명의
- 납입금액
- 메모

월 투자금은 `SCR-022 투자 내역`의 핵심 원천 데이터로 관리한다.

같은 월에 여러 번 납입할 수 있으며, 각각의 납입일과 금액을 보존한다.

## 7. 매수/매도 제안

월 투자금이 입력되면 현재 보유비중과 목표비중을 기준으로 종목별 거래 방향과 금액을 계산한다.

예시:

```text
종목           현재비중   목표비중   제안
샘플 ETF A      32%       40%       300,000원 매수
샘플 ETF B      38%       35%        80,000원 매도
샘플 ETF C      30%       25%       220,000원 매도
```

제안 정보 후보:

- 종목명
- 현재 평가금액
- 현재 비중
- 목표 비중
- 비중 차이
- 제안 거래 방향(매수/매도/유지)
- 제안 금액
- 현재가 기준 예상 수량

실제 주문을 앱에서 실행하지 않는다. 사용자가 증권사에서 직접 주문한 뒤 차곡에서 완료 상태만 기록한다.

## 8. 매수 완료 / 매도 완료

제안된 거래별로 다음 상태를 둘 수 있다.

```text
대기
매수 완료
매도 완료
건너뜀
```

완료 처리 시 실제 매수일·단가·수량을 상세 입력하는 것은 필수가 아니다.

최소 기록 후보:

- 처리일
- 처리 상태
- 제안 금액
- 메모

실제 체결로 인해 보유수량 또는 평균매입가가 달라진 경우 사용자가 최종 값을 수정한다.

## 9. 종목 상세

종목 상세에서는 다음 정보를 제공한다.

- 종목명 / 티커
- 투자계좌
- 보유수량
- 평균매입가
- 현재가
- 평가금액
- 평가손익
- 단순 수익률
- 현재 비중
- 목표 비중
- 가격 데이터 조회일시

본인 보유 종목인 경우 다음 값을 수정할 수 있다.

- 보유수량
- 평균매입가
- 목표 비중

종목별 매수 lot 목록은 제공하지 않는다.

## 10. 평균매입가 보정

평균매입가는 앱이 모든 체결내역을 역산하여 완전 자동 계산하는 것을 기본으로 하지 않는다.

사용자가 실제 증권사 계좌의 평균매입가와 비교하여 필요 시 최종 값을 직접 수정할 수 있어야 한다.

평균매입가 변경 시:

- 변경일시를 기록한다.
- 가능하면 변경 전 값을 이력으로 남긴다.
- 기존 월 투자금 납입 이력을 삭제하거나 변경하지 않는다.

## 11. 가격 데이터 정책

- 현재 시세 조회 실패 시 마지막 정상 가격을 사용할 수 있다.
- 마지막 정상 가격을 사용하는 경우 가격 데이터 조회일시를 제공한다.
- 사용자가 최신 가격인지 과거 가격인지 식별할 수 있어야 한다.

## 12. 권한

- 같은 가계 구성원의 포트폴리오는 조회할 수 있다.
- 월 투자금 납입 등록/수정/비활성화는 해당 계좌 명의자만 수행할 수 있다.
- 보유수량, 평균매입가, 목표비중 수정은 해당 투자계좌 명의자만 수행할 수 있다.
- 다른 구성원의 포트폴리오는 조회 전용이다.

## 13. 시안 데이터

화면 시안의 사람 이름, 계좌명, 금융기관, 종목 예시는 모두 가명/샘플 데이터를 사용한다. 실제 구현에서는 DB/API 조회값으로 치환한다.

## 14. 기존 Excel 연계

- `03_주식투자관리`
- 월별 투자금 납입 관련 시트
- 기존 연도별 투자성과/연복리 수익률 계산 영역

기존 시트의 실제 계산식과 화면 결과를 기준으로 앱 계산 로직을 회귀 검증한다.

## 15. 확정 사항

- 종목별 상세 매수 lot 추적은 필수 기능에서 제외
- 계좌별 월 투자금 납입을 원천 데이터로 관리
- 동일 월 복수 납입 가능
- 현재/목표 비중을 기준으로 매수·매도 제안 제공
- 앱은 실제 주문을 실행하지 않음
- 사용자는 `매수 완료` / `매도 완료` 중심으로 처리
- 최종 보유수량과 평균매입가는 사용자가 보정 가능
- 종목별 수익률은 평균매입가 대비 현재가 기반 단순 수익률 제공
- 연환산 수익률은 계좌/포트폴리오의 납입 현금흐름을 기준으로 계산
- 정확한 연복리 계산식은 기존 자산관리 시트와 결과 일치 검증 후 확정

## 16. 추후 확정

- 매수/매도 제안 알고리즘의 정확한 계산식
- 목표비중 합계 검증 정책
- 매수 가능 단위 및 ETF 1주 미만 금액 처리
- 매도 제안 허용 여부 또는 신규 투자금으로만 비중 조정하는 모드 제공 여부
- 배당금의 투자성과 포함 방식
- 수수료/세금 반영 방식
- 환율 변동을 포함한 해외자산 처리 방식
- 평균매입가 변경이력 보존 수준
