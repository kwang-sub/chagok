# SCR-001 홈 대시보드

> 상태: 1차 화면 명세(Draft)
> 상위 문서: `docs/product/03-screen-specification.md`
> 디자인 기준: 대화에서 확정한 차곡 PC/Mobile 기준 UI

## 1. 화면 목적

가계의 현재 재무상태와 최근 변화를 앱 진입 직후 한눈에 파악할 수 있도록 한다.

홈은 상세 관리 화면이 아니라 요약과 탐색의 시작점으로 사용한다. 사용자는 홈에서 이상 변화나 관심 영역을 확인한 뒤 자산, 투자, 지출, 현금흐름, 부채의 상세 화면으로 이동한다.

## 2. 화면 설계 원칙

- 모바일 우선(Mobile First)으로 설계한다.
- 순자산을 홈에서 가장 중요한 지표로 표현한다.
- 정보 밀도를 과도하게 높이지 않고 핵심 지표와 변화량을 우선한다.
- 밝은 배경, 충분한 여백, 민트/초록 계열 포인트를 기본 디자인 방향으로 한다.
- 장식 요소는 최소화하되 `순자산 추이` 영역에는 차곡의 브랜드 의미를 표현하는 계단형 시각 요소를 사용할 수 있다.
- PC와 모바일에서 동일한 데이터를 제공하되 배치와 노출 우선순위는 화면 크기에 따라 변경한다.
- 금액은 실제 값을 반올림하지 않는다.

## 3. 조회 범위

화면 상단에서 조회 대상을 전환할 수 있다.

```text
가계 전체 / 구성원 A / 구성원 B / ...
```

- 기본값은 `가계 전체`로 한다.
- 같은 가계에 소속된 구성원만 선택할 수 있다.
- 선택한 구성원에 따라 홈의 자산, 투자, 지출, 현금흐름, 부채 데이터가 함께 변경된다.
- 다른 가계 또는 소속되지 않은 사용자의 데이터는 노출하지 않는다.
- 홈은 조회 중심 화면이므로 다른 구성원의 데이터를 선택해도 조회할 수 있다.

## 4. PC 화면 구성

```text
┌──────────────┬─────────────────────────────────────────────────────────┐
│ 차곡          │ 안녕하세요. 우리 집 자산을 차곡차곡 쌓아가고 있어요.      │
│              │                    [가계 전체 ▼] [기준월/기준일]          │
│ 홈           ├─────────────────────────────────────────────────────────┤
│ 자산          │ 순자산                                                   │
│ 투자          │ 000,000,000원                                            │
│ 지출          │ 전월 대비 +00,000,000원 (+0.0%)                           │
│ 현금흐름      │                                                         │
│ 부채          │ [총자산]       [총부채]       [투자자산]                  │
│ 보고서        ├─────────────────────────────────────────────────────────┤
│              │ 순자산 추이                         이번 달 현금흐름       │
│ 설정          │ [        Line Chart       ]          수입 / 지출 / 잉여    │
│              │                  ▂ ▃ ▅ ▆ ▇ 차곡                           │
│              ├───────────────────────────────┬─────────────────────────┤
│              │ 투자 요약                     │ 지출 요약                │
│              │ 평가금액 / 손익 / 수익률       │ 총지출 / 주요 카테고리    │
│              ├───────────────────────────────┼─────────────────────────┤
│              │ 카드 실적                     │ 최근 거래                │
│              └───────────────────────────────┴─────────────────────────┘
└──────────────┴─────────────────────────────────────────────────────────┘
```

PC에서는 좌측 사이드바를 고정 내비게이션으로 사용하고 콘텐츠 영역은 카드형 다열 레이아웃을 사용한다.

## 5. Mobile 화면 구성

```text
┌─────────────────────────────┐
│ 차곡              [알림/프로필] │
│ [가계 전체 ▼] [기준월/기준일]   │
├─────────────────────────────┤
│ 순자산                       │
│ 000,000,000원                │
│ 전월 대비 +00,000,000원       │
│                              │
│ [총자산]          [총부채]     │
├─────────────────────────────┤
│ 순자산 추이                   │
│ [       Line Chart        ]  │
│             ▂ ▃ ▅ ▆ ▇ 차곡   │
├─────────────────────────────┤
│ 이번 달 현금흐름              │
│ 수입 / 지출 / 잉여현금         │
├─────────────────────────────┤
│ 투자 요약                     │
├─────────────────────────────┤
│ 지출 요약                     │
├─────────────────────────────┤
│ 최근 거래                     │
├─────────────────────────────┤
│ 홈   자산   투자   지출   더보기 │
└─────────────────────────────┘
```

모바일에서는 세로 스크롤을 기본으로 하고 핵심 정보 순서를 `순자산 → 추이 → 현금흐름 → 투자 → 지출 → 최근 거래`로 한다.

## 6. 영역별 상세 명세

### 6.1 상단 영역

표시 정보:

- 차곡 로고/서비스명
- 간단한 인사 또는 홈 설명 문구
- 현재 조회 중인 가계/구성원
- 기준월 또는 기준일
- 사용자 프로필 진입점

동작:

- 가계/구성원 선택
- 기준월/기준일 변경
- 프로필/설정 이동

### 6.2 순자산 Hero 영역

홈의 최우선 정보로 표시한다.

표시 정보:

- 순자산
- 전월 대비 증감 금액
- 전월 대비 증감률
- 총자산
- 총부채
- 투자자산 요약

계산 기준:

```text
순자산 = 총자산 - 총부채
```

투자자산은 총자산에 포함하며 중복 합산하지 않는다.

동작:

- 총자산 선택 → `SCR-010 자산 현황`
- 총부채 선택 → `SCR-011 부채 관리`
- 투자자산 선택 → `SCR-020 투자 포트폴리오`

### 6.3 순자산 추이

표시 정보:

- 월별 순자산 Line Chart
- 조회 기간
- 현재 시점 순자산
- 필요 시 전월/전년 대비 변화

기본 기간은 화면 설계 과정에서 확정한다.

브랜드 표현:

- 그래프 자체의 데이터 표현을 방해하지 않는 범위에서 마지막 데이터 지점 부근에 계단처럼 자산이 쌓이는 형태의 간결한 `차곡` 시각 요소를 사용할 수 있다.
- 캐릭터 중심 또는 유아적인 일러스트는 사용하지 않는다.
- 시각 요소는 장식이며 실제 데이터 포인트를 가리거나 값으로 오인되게 하지 않는다.

동작:

- 영역 선택 → `SCR-012 순자산 추이`

### 6.4 이번 달 현금흐름

표시 정보:

- 총수입
- 총지출
- 저축
- 투자
- 잉여현금

홈에서는 모든 세부 항목보다 핵심 흐름을 빠르게 비교할 수 있도록 요약한다.

동작:

- 영역 선택 → `SCR-040 현금흐름 현황`

### 6.5 투자 요약

표시 정보:

- 투자 평가금액
- 평가손익
- 수익률
- 주요 보유자산 또는 자산배분 요약

시세 조회 실패 시 마지막 정상 가격 또는 기준가격 사용 여부는 Market Price 정책 확정 후 반영한다.

동작:

- 영역 선택 → `SCR-020 투자 포트폴리오`

### 6.6 지출 요약

표시 정보:

- 이번 달 총지출
- 전월 대비 증감
- 주요 지출 카테고리
- 필요 시 예산 대비 상태

예산 기능은 별도 기능 범위 확정 전까지 선택 항목으로 둔다.

동작:

- 영역 선택 → `SCR-030 지출 대시보드`

### 6.7 카드 실적

PC에서는 공간이 충분한 경우 홈 요약 영역으로 제공한다. 모바일에서는 우선순위를 낮추고 지출 화면에서 확인하도록 축약하거나 생략할 수 있다.

표시 정보:

- 주요 카드명
- 현재 인정실적
- 목표 실적
- 달성률 또는 부족금액

동작:

- 영역 선택 → `SCR-032 카드 실적`

### 6.8 최근 거래

표시 정보:

- 최근 거래일
- 가맹점/거래명
- 카테고리
- 명의
- 금액

홈에서는 최근 일부 거래만 노출한다.

동작:

- 거래 선택 → 거래 상세 조회
- 전체보기 → `SCR-031 거래 내역`

다른 구성원의 거래도 같은 가계라면 조회할 수 있으나 수정/비활성화 기능은 해당 거래 당사자에게만 제공한다.

## 8. 데이터 상태

### Empty

가계에 아직 자산 데이터가 없는 경우 순자산을 임의로 `0원`만 표시하기보다 최초 등록 행동을 안내한다.

```text
아직 등록된 자산이 없습니다.
첫 자산을 등록하고 차곡을 시작해보세요.
[자산 등록]
```

### Loading

- 카드 영역별 Skeleton UI를 사용한다.
- 전체 화면을 하나의 로딩 화면으로 막지 않는다.

### Partial Data

예: 자산/지출은 정상이나 외부 ETF 가격 조회만 실패한 경우

- 정상 데이터는 그대로 표시한다.
- 실패한 영역에만 데이터 갱신 실패 상태를 표시한다.
- 홈 전체를 오류 화면으로 전환하지 않는다.

### Error

홈 핵심 데이터 자체를 조회할 수 없는 경우 오류 안내와 재시도 동작을 제공한다.

### Permission Denied

사용자가 현재 가계에 접근할 수 없는 경우 재무 데이터를 표시하지 않는다.

## 9. 금액 표시

- 원화는 천 단위 구분자를 사용한다. 예: `123,456,789원`
- 실제 금액 데이터는 반올림하지 않는다.
- 홈에서 공간을 줄이기 위해 `1.2억`, `3.5천만`처럼 금액 자체를 축약 표시하는 것은 기본값으로 사용하지 않는다.
- 수익률 등 비율의 화면 표시 자릿수는 별도 공통 표시 규칙에서 확정한다.
- 계산 및 API/DB 정밀도 정책은 `04-feature-requirements.md`의 `BigDecimal`, `DECIMAL/NUMERIC` 원칙을 따른다.

## 10. 기존 Excel 연계

- `01_대시보드`
- `06_월수입분석`
- `07_순자산추적`
- 투자/지출/카드 요약에 필요한 관련 시트

## 11. Figma 전이 기준

Figma Frame은 다음 이름을 사용한다.

```text
SCR-001 홈 대시보드 / Mobile
SCR-001 홈 대시보드 / Desktop
```

기준 UI 이미지의 디자인 언어를 유지한다.

- 밝고 간결한 화면
- 한눈에 들어오는 정보 계층
- 흰색 중심 배경과 민트/초록 포인트
- 충분한 여백
- 과도한 장식/캐릭터 사용 금지
- 순자산 추이에만 차곡의 의미를 살린 절제된 계단형 시각 요소 사용

## 12. 추가 논의 항목

다음 항목은 다른 화면 및 업무 규칙과 함께 확정한다.

- 홈 순자산 추이의 기본 조회 기간
- 홈에서 카드 실적을 모바일에도 노출할지 여부
- 예산 기능 도입 여부 및 지출 요약 노출 방식
- 투자 시세 조회 실패 시 마지막 정상 가격 표시 정책
- 알림 기능 도입 시 홈 상단 알림 진입점 제공 여부
