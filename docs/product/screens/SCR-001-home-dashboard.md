# SCR-001 홈 대시보드

> 상태: 화면 구성 확정
> 상위 문서: `docs/product/03-screen-specification.md`
> 디자인 기준: 대화에서 확정한 차곡 PC/Mobile 기준 UI 및 카드 실적 포함 최종 시안

## 1. 화면 목적

가계의 현재 재무상태와 최근 변화를 앱 진입 직후 한눈에 파악할 수 있도록 한다.

홈은 상세 관리 화면이 아니라 요약과 탐색의 시작점으로 사용한다. 사용자는 홈에서 이상 변화나 관심 영역을 확인한 뒤 자산, 투자, 지출, 현금흐름, 부채의 상세 화면으로 이동한다.

## 2. 화면 설계 원칙

- 모바일 우선(Mobile First)으로 설계한다.
- 순자산을 홈에서 가장 중요한 지표로 표현한다.
- 정보 밀도를 과도하게 높이지 않고 핵심 지표와 변화량을 우선한다.
- 밝은 배경, 충분한 여백, 민트/초록 계열 포인트를 기본 디자인 방향으로 한다.
- PC와 모바일에서 동일한 핵심 데이터를 제공하되 배치와 노출 방식은 화면 크기에 따라 변경한다.
- 홈에서는 최근 거래내역 대신 카드 실적 현황을 제공한다.
- 금액은 실제 값을 반올림하지 않는다.

## 3. 조회 범위

화면 상단에서 조회 대상을 전환할 수 있다.

```text
가계 전체 / 구성원 A / 구성원 B / ...
```

- 기본값은 `가계 전체`로 한다.
- 같은 가계에 소속된 구성원만 선택할 수 있다.
- 선택한 구성원에 따라 홈의 자산, 투자, 지출, 현금흐름, 부채 및 카드 실적 데이터가 함께 변경된다.
- 다른 가계 또는 소속되지 않은 사용자의 데이터는 노출하지 않는다.
- 홈은 조회 중심 화면이므로 다른 구성원의 데이터를 선택해도 조회할 수 있다.

## 4. PC 화면 구성

```text
┌──────────────┬─────────────────────────────────────────────────────────┐
│ 차곡          │ 안녕하세요. 우리 집 자산을 한눈에 확인해 보세요.          │
│              │                    [가계 전체 ▼] [기준월/기준일]          │
│ 홈           ├─────────────────────────────────────────────────────────┤
│ 자산          │ [순자산 Hero]     [총자산] [총부채] [가용자금]            │
│ 투자          ├───────────────────────────────┬─────────────────────────┤
│ 지출          │ 순자산 추이                    │ 이번 달 현금흐름          │
│ 현금흐름      │ 지난달 → 이번달                │ 수입 / 지출 / 투자 / 잔여  │
│ 부채          ├───────────────────────────────┼─────────────────────────┤
│ 보고서        │ 투자 포트폴리오 요약            │ 이번 달 지출 요약          │
│ 설정          ├─────────────────────────────────────────────────────────┤
│              │ 카드 실적 현황                                            │
│              │ ‹ [카드1] [카드2] [카드3] [카드4] ›        [전체 카드 >] │
│              └─────────────────────────────────────────────────────────┘
└──────────────┴─────────────────────────────────────────────────────────┘
```

PC에서는 좌측 사이드바를 고정 내비게이션으로 사용하고 콘텐츠 영역은 카드형 다열 레이아웃을 사용한다. 카드 실적 현황은 콘텐츠 하단의 가로형 Carousel로 제공한다.

## 5. Mobile 화면 구성

```text
┌─────────────────────────────┐
│ 차곡                   [프로필] │
│ [가계 전체 ▼] [기준월/기준일]   │
├─────────────────────────────┤
│ 순자산 Hero                  │
│ 000,000,000원                │
│ 전월 대비 +00,000,000원       │
├─────────────────────────────┤
│ 총자산     총부채     가용자금   │
├─────────────────────────────┤
│ 이번 달 현금흐름              │
├─────────────────────────────┤
│ 투자 포트폴리오 요약          │
├─────────────────────────────┤
│ 이번 달 지출 요약             │
├─────────────────────────────┤
│ 카드 실적 현황                │
│ [ 카드1 ] [ 카드2 → ]         │
│       ● ○ ○ ○                │
├─────────────────────────────┤
│ 홈   자산   투자   지출   더보기 │
└─────────────────────────────┘
```

모바일에서는 세로 스크롤을 기본으로 하고 카드 실적은 좌우 Swipe 가능한 Carousel로 제공한다.

## 6. 영역별 상세 명세

### 6.1 상단 영역

표시 정보:

- 차곡 로고/서비스명
- 간단한 인사 또는 홈 설명 문구
- 현재 조회 중인 가계/구성원
- 기준월 또는 기준일
- 사용자 프로필 진입점

동작:

- 가계/구성원 선택
- 기준월/기준일 변경
- 프로필/설정 이동

알림 기능은 초기 범위에서 제외하고 추후 도입한다.

### 6.2 순자산 Hero 및 주요 자산 지표

홈의 최우선 정보로 표시한다.

표시 정보:

- 순자산
- 전월 대비 증감 금액
- 전월 대비 증감률
- 총자산
- 총부채
- 가용자금

계산 기준:

```text
순자산 = 총자산 - 총부채
```

투자자산은 총자산에 포함하며 중복 합산하지 않는다.

`가용자금`의 정확한 포함 범위와 계산식은 현금성 자산 및 현금흐름 도메인 설계 시 확정한다.

동작:

- 총자산 선택 → `SCR-010 자산 현황`
- 총부채 선택 → `SCR-011 부채 관리`

### 6.3 순자산 추이

표시 정보:

- 지난달 순자산
- 이번달 순자산
- 지난달 대비 이번달 변화
- 두 시점의 순자산을 비교할 수 있는 추이 시각화

홈의 기본 비교 기간은 **지난달과 이번달**로 한다. 장기간 추이는 `SCR-012 순자산 추이` 상세 화면에서 제공한다.

동작:

- 영역 선택 → `SCR-012 순자산 추이`

### 6.4 이번 달 현금흐름

표시 정보:

- 총수입
- 총지출
- 투자
- 잔여금액

홈에서는 핵심 흐름을 빠르게 비교할 수 있도록 요약한다. 저축 등 세부 분류의 표현 방식은 `SCR-040` 상세 설계에서 보완한다.

동작:

- 영역 선택 → `SCR-040 현금흐름 현황`

### 6.5 투자 포트폴리오 요약

표시 정보:

- 투자 평가금액
- 평가손익
- 수익률
- 주요 보유자산 또는 자산배분 요약
- 투자 가격 데이터 조회일시

시세 조회에 실패한 경우 마지막으로 정상 조회된 가격을 사용한다. 사용자가 현재 표시된 가격의 기준 시점을 알 수 있도록 투자 영역에 해당 가격 데이터의 조회일시를 함께 표시한다.

외부 가격이 최신 상태가 아닌 경우에도 평가금액을 숨기지 않되 데이터 조회일시를 통해 기준 시점을 명확히 한다. 마지막 정상 가격의 저장 및 갱신 방식은 Market Price 아키텍처 설계에서 구체화한다.

동작:

- 영역 선택 → `SCR-020 투자 포트폴리오`

### 6.6 이번 달 지출 요약

표시 정보:

- 이번 달 총지출
- 전월 대비 증감
- 주요 지출 카테고리

예산 기능은 초기 범위에서 제외하고 추후 도입한다. 초기 홈 지출 요약에서는 예산 대비 금액이나 예산 소진율을 표시하지 않는다.

동작:

- 영역 선택 → `SCR-030 지출 대시보드`

### 6.7 카드 실적 현황

홈에서 PC와 Mobile 모두 카드 실적을 제공한다.

카드별 표시 정보:

- 카드명
- 명의
- 현재 인정실적
- 목표 실적
- 달성률
- 목표까지 부족금액
- 결제일 등 카드 실적 확인에 필요한 보조정보(필요 시)

#### PC

- 여러 카드를 한 행의 카드 목록으로 표시한다.
- 표시 가능한 개수를 초과하면 좌우 이동 버튼으로 Carousel을 이동한다.
- 사용자가 특정 카드를 직접 선택하여 확인할 수 있다.
- `전체 카드` 동작을 통해 `SCR-032 카드 실적`으로 이동한다.

#### Mobile

- 카드 목록을 가로 Swipe 가능한 Carousel로 표시한다.
- 다음 카드의 일부가 보이도록 구성하여 좌우 Swipe 가능성을 인지할 수 있게 한다.
- 현재 Carousel 위치를 Pagination Dot으로 표현할 수 있다.
- 카드를 선택하면 해당 카드의 상세 실적 또는 `SCR-032 카드 실적`으로 이동한다.

#### 조회 범위

- `가계 전체` 선택 시 같은 가계 구성원의 카드를 함께 조회할 수 있다.
- 특정 구성원을 선택하면 해당 구성원의 카드만 표시한다.
- 다른 구성원의 카드 실적은 조회할 수 있으나 카드 설정의 수정/비활성화는 카드 당사자만 수행한다.

## 7. 홈에서 제외하는 정보

### 최근 거래내역

최근 거래내역은 홈 대시보드에서 제공하지 않는다.

- 상세 거래는 `SCR-031 거래 내역`에서 조회한다.
- 홈의 제한된 공간은 자산상태, 현금흐름, 투자, 지출 및 카드 실적과 같이 주기적으로 확인할 가치가 높은 요약정보에 사용한다.

## 8. 반응형 우선순위

| 우선순위 | 영역 | Mobile | Desktop |
|---|---|---|---|
| 1 | 순자산 | 필수 | 필수 |
| 2 | 총자산/총부채/가용자금 | 필수 | 필수 |
| 3 | 순자산 추이 | 필요 시 요약 표현 | 필수 |
| 4 | 현금흐름 | 필수 | 필수 |
| 5 | 투자 요약 | 필수 | 필수 |
| 6 | 지출 요약 | 필수 | 필수 |
| 7 | 카드 실적 | Swipe Carousel | 가로 Carousel |

모바일에서는 화면 밀도를 낮추기 위해 PC의 차트가 더 간결한 지표/그래프로 변경될 수 있다.

## 9. 데이터 상태

### Empty

가계에 아직 자산 데이터가 없는 경우 순자산을 임의로 `0원`만 표시하기보다 최초 등록 행동을 안내한다.

```text
아직 등록된 자산이 없습니다.
첫 자산을 등록하고 차곡을 시작해보세요.
[자산 등록]
```

카드가 없는 경우 카드 실적 영역에는 카드 등록 또는 카드 설정 화면으로 이동할 수 있는 Empty State를 제공한다.

### Loading

- 카드 영역별 Skeleton UI를 사용한다.
- 전체 화면을 하나의 로딩 화면으로 막지 않는다.

### Partial Data

예: 자산/지출은 정상이나 외부 ETF 가격 조회만 실패한 경우

- 정상 데이터는 그대로 표시한다.
- ETF 가격 조회 실패 시 마지막 정상 가격을 사용한다.
- 투자 영역에 가격 데이터 조회일시를 표시하여 최신 데이터가 아님을 사용자가 확인할 수 있도록 한다.
- 홈 전체를 오류 화면으로 전환하지 않는다.

### Error

홈 핵심 데이터 자체를 조회할 수 없는 경우 오류 안내와 재시도 동작을 제공한다.

### Permission Denied

사용자가 현재 가계에 접근할 수 없는 경우 재무 데이터를 표시하지 않는다.

## 10. 금액 표시

- 원화는 천 단위 구분자를 사용한다. 예: `123,456,789원`
- 실제 금액 데이터는 반올림하지 않는다.
- 홈에서 공간을 줄이기 위해 `1.2억`, `3.5천만`처럼 금액 자체를 축약 표시하는 것은 기본값으로 사용하지 않는다.
- 수익률 등 비율의 화면 표시 자릿수는 별도 공통 표시 규칙에서 확정한다.
- 계산 및 API/DB 정밀도 정책은 `04-feature-requirements.md`의 `BigDecimal`, `DECIMAL/NUMERIC` 원칙을 따른다.

## 12. Figma 전이 기준

Figma Frame은 다음 이름을 사용한다.

```text
SCR-001 홈 대시보드 / Mobile
SCR-001 홈 대시보드 / Desktop
```

최종 확정 시안의 디자인 언어를 기준으로 한다.

- 밝고 간결한 화면
- 한눈에 들어오는 정보 계층
- 흰색 중심 배경과 민트/초록 포인트
- 충분한 여백
- 과도한 장식/캐릭터 사용 금지
- PC 카드 실적은 가로형 카드 Carousel
- Mobile 카드 실적은 Swipe Carousel
- 홈에서 최근 거래내역은 제외

## 13. 확정 및 추후 항목

### 확정

- 홈 순자산 추이 기본 비교 기간: 지난달 / 이번달
- PC/Mobile 홈에 카드 실적 현황 제공
- PC: 가로 카드 목록 + Carousel 이동/선택
- Mobile: 좌우 Swipe Carousel
- 최근 거래내역 홈에서 제외
- 투자 가격 조회 실패 시 마지막 정상 가격 사용
- 투자 영역에 가격 데이터 조회일시 표시

### 추후 도입

- 예산 기능
- 알림 기능

### 도메인 설계 시 확정

- 가용자금의 정확한 계산식 및 포함 자산 범위
- 카드 실적의 카드사별 인정/제외 계산 규칙
