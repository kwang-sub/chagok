# 차곡 투자 성과 계산 명세

> 상태: 초안(Draft)
> 문서 목적: 기존 자산관리 Excel에서 사용하던 연도별 투자 성과와 XIRR 계산 기준을 차곡의 화면·도메인·검증 기준으로 명확히 정의한다.

## 1. 적용 범위

이 문서는 다음 기능의 기준으로 사용한다.

- `SCR-020 투자 포트폴리오`
- `SCR-022 투자 내역`
- `FTR-204 평가손익 및 수익률`
- `FTR-206 투자내역 관리`
- 향후 연도별 투자 성과 조회 기능

임시 운영 중인 `우리자산관리`의 `03_주식투자관리`, `08_광섭_투자내역관리`, `09_자민_투자내역관리`와 기존 legacy 투자금액현황 계산식을 기준 자료로 사용한다.

## 2. 화면 표시 기준

투자 포트폴리오 화면에서 기존 현재 평가 중심 정보에 다음 성과 정보를 추가한다.

### 2.1 전체 투자 성과

- 총 투자원금
- 총 평가금액
- 평가손익
- 총 수익률
- 연 복리 수익률(XIRR)

### 2.2 연도별 투자 성과

| 항목 | 의미 |
|---|---|
| 연도 | 투자 성과 기준 연도 |
| 해당연도 투자액 | 해당 연도 외부에서 투자계좌로 순유입된 투자금 |
| 연초 평가액 | 직전 연도 마지막 평가액 |
| 연초 평가액+투자 | 연초 평가액 + 해당연도 투자액 |
| 연말/현재 평가액 | 과거 연도는 연말 평가액, 현재 연도는 최신 평가액 |
| 연간 수익률 | 기존 Excel 호환 방식의 단순 연간 성과율 |

### 2.3 연도·계좌별 투자금액

- 연도
- 계좌
- 해당 연도 투자금액 합계

개인연금, IRP, 퇴직연금, ISA 등 계좌별 투자금의 연도별 유입 규모를 확인할 수 있어야 한다.

## 3. 계산 규칙

### 3.1 해당연도 투자액

```text
해당연도 투자액 = 해당 연도에 발생한 외부 투자금 순유입 합계
```

계좌 간 내부 이동은 총 투자원금이 증가하지 않도록 외부 투자금과 구분해야 한다.

### 3.2 연초 평가액

```text
연초 평가액 = 직전 연도의 마지막 확정 평가액
```

최초 투자 연도처럼 직전 연도 평가액이 없는 경우 `0`으로 처리한다.

### 3.3 연간 수익률

기존 Excel과의 결과 호환을 우선하여 다음 공식을 적용한다.

```text
기준 투자금액 = 연초 평가액 + 해당연도 투자액
연간 수익률 = (연말/현재 평가액 - 기준 투자금액) / 기준 투자금액
```

동일한 식을 다음과 같이 표현할 수 있다.

```text
연간 수익률 = 연말/현재 평가액 / 기준 투자금액 - 1
```

기준 투자금액이 `0`인 경우 0으로 처리하거나 표시 불가 상태로 반환하여 0 나누기 오류가 발생하지 않아야 한다.

이 지표는 투자 시점별 자금 가중을 반영한 엄밀한 시간가중수익률(TWR)이 아니다. 기존 Excel의 사용자 경험과 과거 수치 재현을 위한 호환 지표로 유지한다.

### 3.4 총 수익률

```text
평가손익 = 현재 총 평가금액 - 총 투자원금
총 수익률 = 평가손익 / 총 투자원금
```

총 투자원금이 0인 경우 0 나누기 오류가 발생하지 않아야 한다.

### 3.5 연 복리 수익률(XIRR)

XIRR은 각 투자금의 실제 투입일을 반영한다.

```text
현금흐름
- 각 투자일: 투자금액 × -1
- 기준일: 현재 총 평가금액 × +1

XIRR = 위 날짜별 현금흐름의 연환산 내부수익률
```

XIRR 계산에는 최소 하나의 음수 현금흐름과 하나의 양수 현금흐름이 필요하다. 계산 불가능한 데이터 조합은 오류가 아닌 계산 불가 상태로 처리한다.

## 4. 평가금액 기준

- 과거 연도는 해당 연도의 마지막 확정 평가액을 사용한다.
- 현재 연도는 조회 시점의 최신 평가액을 사용한다.
- 현재 평가액에는 보유종목 평가액과 투자계좌 내 예수금 등 투자계좌 총액에 포함하기로 한 항목을 동일 기준으로 포함해야 한다.
- 과거 연도 성과 재현을 위해 연말 평가 스냅샷을 보존해야 한다.

## 5. 투자내역 데이터 기준

연도별 성과와 XIRR 계산을 위해 투자내역에는 최소 다음 데이터가 필요하다.

- 거래일
- 구성원/명의
- 투자계좌
- 금액
- 투자금 흐름 유형
- 메모

향후 투자금 흐름 유형은 최소 다음을 구분할 수 있는 구조로 설계한다.

- 외부 투자금 유입
- 외부 투자금 회수
- 계좌 간 내부 이동

계좌 간 내부 이동은 계좌별 통계에는 나타날 수 있지만 가계 또는 명의의 총 투자원금을 중복 증가시키지 않아야 한다.

## 6. 임시 Excel 적용 기준

`우리자산관리`에서는 앱 개발 전까지 다음 방식으로 운영한다.

- `03_주식투자관리`에 연도별 투자 성과 표를 표시한다.
- 조회 대상(광섭/자민)에 따라 08~09 투자입금 이력을 집계한다.
- 과거 연초/연말 평가액은 기존 legacy 투자금액현황의 확정값을 임시 참조한다.
- 현재 연도 평가액은 `03_주식투자관리`의 현재 계좌 총액을 사용한다.
- XIRR은 08~09의 실제 투자입금 일자와 현재 계좌 총액으로 직접 계산한다.
- 연도·계좌별 투자금액을 함께 표시한다.

legacy 의존은 임시 Excel 호환을 위한 것으로, 차곡 본 개발에서는 도메인 데이터와 평가 스냅샷으로 대체한다.

## 7. 회귀 검증 기준

최소 다음 항목을 검증한다.

- 최초 투자 연도의 연초 평가액이 0으로 계산되는지
- 다음 연도의 연초 평가액이 직전 연도 연말 평가액과 일치하는지
- 해당연도 투자액이 투자입금 이력 합계와 일치하는지
- 현재 연도의 연말/현재 평가액이 최신 계좌 총액과 일치하는지
- 연간 수익률이 기존 Excel 공식과 동일한지
- 연도·계좌별 합계가 투자입금 이력과 일치하는지
- XIRR이 투자일별 현금흐름을 반영하는지
- 명의 전환 시 광섭/자민 데이터가 서로 섞이지 않는지
- 계좌 간 내부 이동이 총 투자원금을 중복 증가시키지 않는지

이 값들은 임시 Excel 수식 변경에 대한 회귀 검증 기준으로 사용하며, 시장가격 변동으로 현재 평가액이 바뀌면 현재 연도 수익률과 XIRR도 함께 변할 수 있다.
