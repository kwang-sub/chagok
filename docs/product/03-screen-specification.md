# 차곡 화면 명세

> 상태: 초안(Draft)
> 문서 목적: 화면별 표시 정보, 사용자 동작, 주요 연결 기능과 공통 UI 정책을 정의한다.

상세 배치와 디자인은 Figma에서 관리하며 본 문서는 기능 및 화면 동작의 기준을 관리한다.

## 1. 공통 UI 정책

### 1.1 등록/수정 화면

차곡은 모바일 우선으로 설계하되 PC와 모바일에서 입력 경험을 다르게 제공할 수 있다.

- PC: 입력 항목이 적고 단순한 등록/수정은 `Modal`을 기본으로 한다.
- Mobile: 등록/수정은 별도 화면을 기본으로 한다.
- 입력 항목이 많거나 단계형 입력, 검색, 파일 첨부, 복잡한 검증이 필요한 기능은 PC에서도 별도 화면을 사용할 수 있다.
- `Drawer`는 상세 조회 또는 보조 편집 등 명확한 사용 목적이 있을 때만 선택적으로 사용한다.

등록/수정 방식은 각 화면의 Figma 설계 시 최종 확정한다.

### 1.2 반응형 기준

차곡은 모바일 우선(Mobile First)으로 화면을 설계한다.

초기 반응형 기준은 다음과 같이 정의한다.

| 구간 | 기준 | 기본 UI 원칙 |
|---|---:|---|
| Mobile | 0 ~ 767px | 하단 탭, 1열 중심, 핵심 정보 우선 |
| Tablet | 768 ~ 1023px | 1~2열 유동 배치, 화면 폭에 따른 정보 재배치 |
| Desktop | 1024px 이상 | 좌측 사이드바, 다열 카드/테이블 활용 |

반응형은 단순 축소가 아니라 화면 크기에 따라 정보의 우선순위와 배치를 변경하는 것을 원칙으로 한다.

### 1.3 공통 데이터 상태

모든 주요 화면은 정상 데이터 상태뿐 아니라 다음 상태를 별도로 설계한다.

- `Empty`: 등록된 데이터가 없음
- `No Result`: 검색 또는 필터 결과가 없음
- `Loading`: 데이터 조회 중
- `Error`: 일반 조회/처리 오류
- `External API Error`: 외부 금융/시세 연동 오류
- `Partial Data`: 일부 데이터만 조회됨
- `Permission Denied`: 조회 또는 작업 권한 없음

빈 데이터 상태에서는 단순히 빈 공간을 노출하지 않고 가능한 경우 다음 행동을 안내한다.

예:

```text
아직 등록된 투자 자산이 없습니다.
[투자 자산 등록]
```

오류/빈 데이터/권한 없음 화면의 상세 디자인은 Figma에서 공통 컴포넌트로 정의한다.

### 1.4 가계/구성원 조회 UI

- 사용자는 자신이 속한 가계 범위에서 `가계 전체` 또는 `구성원별` 조회를 할 수 있다.
- 같은 가계 구성원의 상세 거래 및 재무정보는 조회할 수 있다.
- 다른 가계 또는 소속되지 않은 사용자의 데이터는 조회할 수 없다.
- 등록/수정/비활성화 등 변경 기능의 노출 여부는 해당 데이터의 소유자 및 권한에 따라 결정한다.

## SCR-020 투자 포트폴리오

### 목적

투자자산의 현재 평가상태, 자산배분 및 기간별 투자 성과를 확인한다.

### 표시 정보

- 총 투자원금
- 총 평가금액
- 평가손익
- 총 수익률
- 연 복리 수익률(XIRR)
- 종목명/티커
- 보유수량
- 평균매입가
- 현재가
- 현재비중
- 목표비중
- 비중 차이
- 연도별 투자 성과
  - 연도
  - 해당연도 투자액
  - 연초 평가액
  - 연초 평가액+투자액
  - 연말/현재 평가액
  - 연간 수익률
- 연도·계좌별 투자금액

### 주요 동작

- ETF 검색 및 추가
- 본인 보유수량/매입정보 수정
- 목표비중 설정
- 계좌별/구성원별 필터
- 연도별 투자 성과 확인
- 연도·계좌별 투자금액 확인
- 종목 상세 확인

### 성과 지표 표시 원칙

- `총 수익률`은 현재 평가금액과 총 투자원금의 단순 누적 수익률이다.
- `연간 수익률`은 기존 Excel과의 호환을 위해 `연초 평가액 + 해당연도 투자액` 대비 연말/현재 평가액으로 계산한다.
- `XIRR`은 실제 투자입금 일자를 반영한 연환산 수익률로 별도 표시한다.
- 연간 수익률과 XIRR은 의미가 다르므로 하나의 지표로 통합하지 않는다.
- 상세 계산 규칙은 `06-investment-performance.md`를 따른다.

### 외부 데이터

- 금융위원회 ETF 공공데이터
- Google Finance 가격 PoC

실서비스 가격 Provider 정책은 별도 아키텍처 문서에서 확정한다.

### 기존 Excel 연계

- `03_주식투자관리`
- `08_광섭_투자내역관리`
- `09_자민_투자내역관리`
- legacy 투자금액현황 시트의 과거 연말 평가액

## SCR-022 투자 내역

### 목적

투자에 투입된 자금과 투자 관련 기록을 확인하고 투자 성과 계산의 원천 데이터를 관리한다.

### 표시 정보

- 일자
- 명의
- 계좌
- 투자유형
- 금액
- 메모

### 주요 동작

- 본인 투자내역 등록/수정/비활성화
- 같은 가계 구성원의 투자내역 조회
- 기간/명의/계좌 필터

### 데이터 원칙

- 외부 투자금 유입, 외부 투자금 회수, 계좌 간 내부 이동을 구분할 수 있어야 한다.
- 계좌 간 내부 이동은 명의 또는 가계 전체의 총 투자원금을 중복 증가시키지 않아야 한다.
- 실제 투자일자는 XIRR 계산의 현금흐름 날짜로 사용한다.

### 기존 Excel 연계

- 투자내역 관련 시트(08~09)

## SCR-093 기준정보 설정

### 목적

자산유형, 계좌유형 등 애플리케이션의 공통 선택값을 관리한다.

### 접근 정책

- 특정 시스템 관리자 권한을 가진 계정만 접근할 수 있다.
- 일반 사용자 및 가계 대표자는 기준정보를 조회/선택할 수 있으나 임의로 등록/수정할 수 없다.

### 기존 Excel 연계

- `15_선택값설정`

## SCR-094 데이터 가져오기

### 목적

카드사 파일 등을 업로드하여 거래내역으로 변환한다.

### 단계

1. 파일 선택
2. 파일 형식 확인
3. 카드/명의 매핑
4. 거래 데이터 미리보기
5. 중복검사
6. 가져오기 확정
7. 결과 확인

### 주요 동작

- XLSX/CSV 파일 선택
- 파싱 결과 검증
- 잘못된 행 제외
- 중복거래 제외/선택
- 가져오기 실행

지원 카드사 및 파일형식은 별도 요구사항으로 확정한다.
