# 차곡 화면 명세

> 상태: 초안(Draft)
> 문서 목적: 화면별 표시 정보, 사용자 동작, 주요 연결 기능을 정의한다.

상세 배치와 디자인은 Figma에서 관리하며 본 문서는 기능 기준을 관리한다.

## SCR-001 홈 대시보드

### 목적

가계의 현재 재무상태와 이번 달 현금흐름을 한 화면에서 파악한다.

### 표시 정보

- 총자산
- 총부채
- 순자산
- 전월 대비 순자산 증감
- 투자 평가금액 및 수익률
- 이번 달 수입
- 이번 달 지출
- 이번 달 저축/투자 금액
- 순자산 추이 요약

### 주요 동작

- 자산 상세 이동
- 부채 상세 이동
- 투자 포트폴리오 이동
- 지출 상세 이동
- 현금흐름 상세 이동

### 기존 Excel 연계

- `01_대시보드`
- `06_월수입분석`
- `07_순자산추적`

---

## SCR-010 자산 현황

### 목적

가계가 보유한 금융자산과 관리대상 자산을 한곳에서 관리한다.

### 표시 정보

- 자산명
- 자산유형
- 명의/소유자
- 금융기관
- 계좌 또는 식별정보
- 현재금액
- 만기/기준일(필요한 유형만)

### 주요 동작

- 자산 등록
- 자산 수정
- 자산 비활성화/삭제
- 구성원별 필터
- 자산유형별 필터

### 기존 Excel 연계

- `02_자산현황`

---

## SCR-020 투자 포트폴리오

### 목적

투자자산의 현재 평가상태와 자산배분을 확인한다.

### 표시 정보

- 총 투자원금
- 총 평가금액
- 평가손익/수익률
- 종목명/티커
- 보유수량
- 평균매입가
- 현재가
- 현재비중
- 목표비중
- 비중 차이

### 주요 동작

- ETF 검색 및 추가
- 보유수량/매입정보 수정
- 목표비중 설정
- 계좌별/구성원별 필터
- 종목 상세 확인

### 외부 데이터

- 금융위원회 ETF 공공데이터
- Google Finance 가격 PoC

실서비스 가격 Provider 정책은 별도 아키텍처 문서에서 확정한다.

### 기존 Excel 연계

- `03_주식투자관리`

## SCR-050 거래 가져오기

### 목적

카드사 파일을 업로드하여 거래내역으로 변환한다.

### 단계

1. 파일 선택
2. 파일 형식 확인
3. 카드/명의 매핑
4. 거래 데이터 미리보기
5. 중복검사
6. 가져오기 확정
7. 결과 확인

### 주요 동작

- XLSX/CSV 파일 선택
- 파싱 결과 검증
- 잘못된 행 제외
- 중복거래 제외/선택
- 가져오기 실행

지원 카드사 및 파일형식은 별도 요구사항으로 확정한다.
