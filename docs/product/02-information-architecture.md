# 차곡 정보 구조 및 화면 구성도

> 상태: 초안(Draft)
> 문서 목적: 차곡의 메뉴 구조와 화면 식별자, PC/모바일 내비게이션 정책을 정의한다.

## 1. 설계 원칙

- PC와 모바일 모두 지원하며 기능 우선순위는 동일하게 유지한다.
- 실제 사용 빈도는 모바일이 높을 것으로 예상하므로 화면 설계는 **모바일 우선(Mobile First)** 을 기본으로 한다.
- PC는 **좌측 사이드바**, 모바일은 **하단 탭**을 기본 내비게이션으로 사용한다.
- 자산과 투자는 메뉴를 분리한다. 단, 투자자산은 총자산 및 순자산 계산에 포함한다.
- 수입은 별도 최상위 메뉴로 두지 않고 현금흐름에 통합한다.
- 데이터 가져오기는 일상적으로 탐색하는 핵심 기능보다 관리 기능에 가까우므로 설정 하위에 배치한다.

## 2. 1차 메뉴 구조

```text
차곡
├─ 홈
│  └─ SCR-001 홈 대시보드
│
├─ 자산
│  ├─ SCR-010 자산 현황
│  └─ SCR-012 순자산 추이
│
├─ 투자
│  ├─ SCR-020 투자 포트폴리오
│  ├─ SCR-021 투자 계좌
│  └─ SCR-022 투자 내역
│
├─ 지출
│  ├─ SCR-030 지출 대시보드
│  ├─ SCR-031 거래 내역
│  ├─ SCR-032 카드 실적
│  └─ SCR-033 정기지출
│
├─ 현금흐름
│  ├─ SCR-040 현금흐름 현황
│  ├─ SCR-041 수입 내역
│  └─ SCR-042 정기 현금흐름
│
├─ 부채
│  └─ SCR-011 부채 관리
│
├─ 보고서
│  ├─ SCR-060 월간 보고서
│  └─ SCR-061 순자산 보고서
│
└─ 설정
   ├─ SCR-090 가계/구성원 관리
   ├─ SCR-091 카드 설정
   ├─ SCR-092 카테고리 설정
   ├─ SCR-093 기준정보 설정
   └─ SCR-094 데이터 가져오기
```

메뉴 수와 세부 명칭은 화면 설계 및 기능 구체화 과정에서 조정할 수 있다.

## 3. PC / 모바일 내비게이션

### 3.1 PC

PC에서는 좌측 사이드바를 사용한다.

```text
홈
자산
투자
지출
현금흐름
부채
보고서
설정
```

하위 기능은 사이드바의 하위 메뉴 또는 각 영역의 화면 내부 탐색으로 제공한다.

### 3.2 모바일

모바일에서는 자주 사용하는 기능을 중심으로 하단 탭을 제공한다.

```text
[ 홈 ] [ 자산 ] [ 투자 ] [ 지출 ] [ 더보기 ]
```

`더보기`에서는 다음 영역으로 이동할 수 있다.

```text
현금흐름
부채
보고서
설정
```

모바일에서도 PC와 동일한 기능을 사용할 수 있도록 하되 화면 크기에 맞게 정보의 우선순위와 배치를 조정한다.

## 4. 자산과 투자의 관계

메뉴 관점에서는 자산과 투자를 분리한다.

- `자산`: 예금, 적금, 연금, 보증금, 현금 및 기타 관리 대상 자산의 현황 관리
- `투자`: ETF 등 투자상품의 보유수량, 평균매입가, 평가금액, 수익률, 비중, 투자계좌 및 투자내역 관리

단, 재무 계산에서는 투자자산을 자산에 포함한다.

```text
총자산
= 일반 금융자산
+ 투자자산
+ 기타 관리대상 자산
```

따라서 홈의 총자산 및 순자산과 자산 관련 보고서에는 투자자산이 포함된다.

## 5. 가계 및 구성원 구조

차곡의 자산관리는 개인 단독 사용뿐 아니라 가계 단위 공동 관리를 지원하는 방향으로 설계한다.

기본 가입 흐름은 다음과 같다.

```text
가계 대표자
→ 가계 그룹 생성
→ 구성원 초대
→ 초대받은 사용자가 초대 수락
→ 가계 구성원으로 참여
```

사용자와 가계는 향후 확장 가능성을 고려하여 개념적으로 분리한다.

```text
User
  │
  │ 참여
  ▼
HouseholdMember
  │
  ▼
Household
```

가계 대표자는 그룹 및 구성원 관리 권한을 가진다. 세부 권한 체계는 기능 명세 및 인증/인가 설계 단계에서 확정한다.

한 사용자가 동시에 여러 가계 그룹에 참여할 수 있는지는 아직 확정하지 않는다.

## 6. 주요 사용자 흐름

### 6.1 전체 재무상태 확인

```text
SCR-001 홈
→ 자산/부채/순자산 요약 확인
→ 상세 영역 선택
→ SCR-010 / SCR-011 / SCR-012 이동
```

### 6.2 투자현황 확인

```text
SCR-020 투자 포트폴리오
→ 보유 ETF 평가금액/수익률/비중 확인
→ 투자계좌 선택
→ SCR-021 투자 계좌
→ 상세 거래 확인 시 SCR-022 투자 내역
```

### 6.3 카드 지출 가져오기

```text
SCR-094 데이터 가져오기
→ 파일 선택
→ 컬럼/카드/명의 매핑
→ 중복 검사
→ 가져오기 확정
→ SCR-031 거래 내역
→ SCR-030 지출 대시보드 반영
→ SCR-032 카드 실적 반영
```

### 6.4 현금흐름 확인

```text
SCR-041 수입 내역
+
SCR-031 거래 내역
+
SCR-042 정기 현금흐름
+
SCR-022 투자 내역
→ SCR-040 현금흐름 현황
→ SCR-001 홈 요약 반영
```

## 7. 화면별 목적 요약

| 화면 ID | 화면명 | 핵심 목적 |
|---|---|---|
| SCR-001 | 홈 대시보드 | 가계 전체 재무상태를 한눈에 확인 |

| SCR-012 | 순자산 추이 | 기간별 자산·부채·순자산 변화 확인 |
| SCR-020 | 투자 포트폴리오 | 투자 평가금액, 수익률, 자산비중 확인 |
| SCR-021 | 투자 계좌 | 계좌별 보유자산 및 계좌 정보 관리 |
| SCR-022 | 투자 내역 | 투자 입출금/매수 관련 기록 조회 |
| SCR-030 | 지출 대시보드 | 월 지출 규모와 카테고리별 소비 분석 |
| SCR-031 | 거래 내역 | 카드/지출 거래 검색·분류·수정 |

| SCR-033 | 정기지출 | 반복되는 고정지출 관리 |
| SCR-040 | 현금흐름 현황 | 수입·소비·저축·투자 흐름 비교 |
| SCR-041 | 수입 내역 | 급여/상여/기타수입 관리 |

## 8. 공통 화면 정책 초안

모든 목록형 화면은 가능한 범위에서 다음 필터를 공통으로 제공한다.

- 기간
- 가계 구성원/명의
- 계좌 또는 카드
- 카테고리/유형

금액은 원화 기준을 기본으로 하되 외화 자산 지원 여부는 추후 확정한다.

삭제는 실제 삭제와 비활성화 중 어떤 정책을 사용할지 도메인 설계 시 결정한다.

## 9. Figma 관리 규칙

Figma Frame 이름은 GitHub 문서와 동일한 화면 ID를 사용한다.

예:

```text
SCR-001 홈 대시보드
SCR-020 투자 포트폴리오
SCR-031 거래 내역
```

화면이 분리될 경우 하위 식별자를 사용할 수 있다.

```text
SCR-031-01 거래 상세
SCR-031-02 거래 수정
```

PC와 모바일 화면은 동일한 화면 ID를 공유하고 플랫폼을 Frame 이름에 추가할 수 있다.

```text
SCR-001 홈 대시보드 / PC
SCR-001 홈 대시보드 / Mobile
```

## 10. 미확정 사항

- 한 사용자의 단일/다수 가계 그룹 참여 허용 여부
- 가계 대표자와 일반 구성원의 세부 권한 차이
- 가계 대표자 변경 및 구성원 탈퇴/강제 제외 정책
- 외화 자산 지원 범위
- 데이터 삭제/비활성화 정책

이 항목들은 화면 및 기능 명세를 구체화하면서 결정한다.
