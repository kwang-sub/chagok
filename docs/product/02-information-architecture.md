# 차곡 정보 구조 및 화면 구성도

> 상태: 초안(Draft)
> 문서 목적: 차곡의 메뉴 구조와 화면 식별자를 정의한다.

## 1. 1차 메뉴 구조

```text
차곡
├─ 홈
│  └─ SCR-001 홈 대시보드
│
├─ 자산
│  ├─ SCR-010 자산 현황
│  ├─ SCR-011 부채 관리
│  └─ SCR-012 순자산 추이
│
├─ 투자
│  ├─ SCR-020 투자 포트폴리오
│  ├─ SCR-021 투자 계좌
│  └─ SCR-022 투자 내역
│
├─ 지출
│  ├─ SCR-030 지출 대시보드
│  ├─ SCR-031 거래 내역
│  ├─ SCR-032 카드 실적
│  └─ SCR-033 정기지출
│
├─ 현금흐름
│  ├─ SCR-040 월 현금흐름
│  └─ SCR-041 수입 내역
│
├─ 가져오기
│  └─ SCR-050 거래 가져오기
│
└─ 설정
   ├─ SCR-090 카드 설정
   ├─ SCR-091 카테고리 설정
   └─ SCR-092 기준정보 설정
```

메뉴 수와 명칭은 Figma 화면 설계 과정에서 통합/분리할 수 있다.

## 2. 주요 사용자 흐름

### 2.1 전체 재무상태 확인

```text
SCR-001 홈
→ 자산/부채/순자산 요약 확인
→ 상세 영역 선택
→ SCR-010 / SCR-011 / SCR-012 이동
```

### 2.2 투자현황 확인

```text
SCR-020 투자 포트폴리오
→ 보유 ETF 평가금액/수익률/비중 확인
→ 투자계좌 선택
→ SCR-021 투자 계좌
→ 상세 거래 확인 시 SCR-022 투자 내역
```

### 2.3 카드 지출 가져오기

```text
SCR-050 거래 가져오기
→ 파일 선택
→ 컬럼/카드/명의 매핑
→ 중복 검사
→ 가져오기 확정
→ SCR-031 거래 내역
→ SCR-030 지출 대시보드 반영
→ SCR-032 카드 실적 반영
```

### 2.4 월 현금흐름 확인

```text
SCR-041 수입 내역
+
SCR-031 거래 내역
+
SCR-033 정기지출
+
SCR-022 투자 내역
→ SCR-040 월 현금흐름
→ SCR-001 홈 요약 반영
```

## 3. 화면별 목적 요약

| 화면 ID | 화면명 | 핵심 목적 |
|---|---|---|
| SCR-001 | 홈 대시보드 | 가계 전체 재무상태를 한눈에 확인 |
| SCR-010 | 자산 현황 | 금융자산 및 기타 관리대상 자산 조회/관리 |
| SCR-011 | 부채 관리 | 대출 잔액, 금리, 상환정보 관리 |
| SCR-012 | 순자산 추이 | 기간별 자산·부채·순자산 변화 확인 |
| SCR-020 | 투자 포트폴리오 | 투자 평가금액, 수익률, 자산비중 확인 |
| SCR-021 | 투자 계좌 | 계좌별 보유자산 및 계좌 정보 관리 |
| SCR-022 | 투자 내역 | 투자 입출금/매수 관련 기록 조회 |
| SCR-030 | 지출 대시보드 | 월 지출 규모와 카테고리별 소비 분석 |
| SCR-031 | 거래 내역 | 카드/지출 거래 검색·분류·수정 |
| SCR-032 | 카드 실적 | 카드별 실적 및 목표/부족금액 확인 |
| SCR-033 | 정기지출 | 반복되는 고정지출 및 정기 현금유출 관리 |
| SCR-040 | 월 현금흐름 | 수입·소비·저축·투자 흐름 비교 |
| SCR-041 | 수입 내역 | 급여/상여/기타수입 관리 |
| SCR-050 | 거래 가져오기 | 카드사 파일을 거래 데이터로 변환 |
| SCR-090 | 카드 설정 | 카드명, 명의, 실적 기준 관리 |
| SCR-091 | 카테고리 설정 | 지출 대/소분류 관리 |
| SCR-092 | 기준정보 설정 | 자산유형·계좌유형 등 공통 선택값 관리 |

## 4. 공통 화면 정책 초안

모든 목록형 화면은 가능한 범위에서 다음 필터를 공통으로 제공한다.

- 기간
- 구성원/명의
- 계좌 또는 카드
- 카테고리/유형

금액은 원화 기준을 기본으로 하되 외화 자산 지원 여부는 추후 확정한다.

삭제는 실제 삭제와 비활성화 중 어떤 정책을 사용할지 도메인 설계 시 결정한다.

## 5. Figma 관리 규칙

Figma Frame 이름은 GitHub 문서와 동일한 화면 ID를 사용한다.

예:

```text
SCR-001 홈 대시보드
SCR-020 투자 포트폴리오
SCR-031 거래 내역
```

화면이 분리될 경우 하위 식별자를 사용할 수 있다.

```text
SCR-031-01 거래 상세
SCR-031-02 거래 수정
```

## 6. 미확정 사항

- 모바일 우선/데스크톱 우선 여부
- 하단탭과 사이드바 중 기본 내비게이션 방식
- 자산과 투자 메뉴 통합 여부
- 수입/현금흐름 메뉴 통합 여부
- 구성원 전환 UI

이 항목들은 화면 초안 작성 시 결정한다.
